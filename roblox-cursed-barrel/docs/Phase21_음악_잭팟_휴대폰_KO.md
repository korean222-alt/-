# Phase 21 — 배경음악 · 심장 소리 · 잭팟 · 휴대폰 화면 · 관전 버그

Place: `CursedBarrel_Phase21_Music.rbxl` (보내 주신 Phase 20 파일에 이번 변경만 얹었습니다)

## 해 주실 것 (순서대로)

1. Studio 에서 `CursedBarrel_Phase21_Music.rbxl` 열기
2. **음악 5개 올리기** (아래 "음악 올리기") → ID 를 `ReleaseConfig.lua` 의 `C.Audio` 에 넣기
3. (선택) 버튼 그림 7장 올리기 → `C.Images.Buttons`
4. Play 로 확인 (아래 체크) → **기존 게임에 덮어쓰기로 게시** (아래 "업데이트 올리기")

ID 는 숫자만 보내 주셔도 제가 넣어 드립니다.

| 사진 4 : 관전 안 하는데 "관전 종료 · 다음 판 참가" 가 뜸 | 버그였습니다. 탈락하면 자동으로 그 테이블 관전이 켜지는데, 판이 끝나도 꺼지지 않았습니다. 이제 판이 끝나고 4초 뒤 저절로 꺼지고, 버튼 위에 "👀 관전 중 · 테이블 이름" 이 붙습니다 (휴대폰에서는 작게) |

| 밤에 어두운 곳 | 등불 자리를 지도로 재 보니 **테이블이 있는 양옆 줄(가운데에서 20~40칸)과 등불 아치 사이**가 비어 있었습니다. 그 위에 은은한 빛 14개를 높이 띄웠습니다 (밤 · 안개 · 폭풍에만 켜짐). 밤 · 안개 · 폭풍 주변광도 한 단계 밝혔습니다. 휴대폰 켜는 빛 수 14 → 20. 게임 중 검은 배경(개인 무대)은 해적에 집중하라고 일부러 둔 것인데, 바닥 가장자리까지 보이게 조금 밝혔습니다 |
| 어려운 경지부터 0.02초씩 빨라지게 · 판이 오래 가게 | 잡기 창이 **0.40초 아래로 내려가는 순간부터는 잡을 때마다 0.02초씩만** 좁아집니다 (2인 판 : 0.53 → 0.40 → 0.38 → … → 0.20). 분노한 해적은 **16번**을 잡은 다음 (예전 6번). 잘하는 사람은 훨씬 오래 버팁니다 |
| 3인 이상에서 지면 "패배 3등" 다음에 또 "패배" | 버그였습니다. 탈락할 때 "패배 · 3위" 를 보여 주고, 판이 끝날 때 한 번 더 "패배" 를 띄웠습니다. 이제 한 번만 뜹니다 (2인 판도 같은 문제였습니다) |
| 출석 · 상점 아이콘이 못생김 | 사진 3처럼 버튼 판에 레고 같은 점무늬 + 파트로 만든 3D 소품이었습니다. 점무늬를 걷어내고 가운데가 빛나는 판으로 바꿨고, **만화풍 그림 7장**을 새로 그렸습니다 (`ui/buttons/*.png`, 미리보기 `ui/buttons/preview.png`). 올리기 전에는 큰 그림 문자(🛒📜💣📅🎡🎟️🧭)가 보입니다 |
| 출석체크 돈 아이콘 크게 | 칸을 거의 꽉 채우게 키웠습니다 (66 → 88) |
| 무엇을 얻으면 "얻었다" 가 반짝이며 뜨게 | 화면 가운데 **"획득!"** 창 : 도는 빛살 · 반짝이는 별 · 돈 그림 · 동전 소리. 출석 · 룰렛 · 코드 · 그룹 보상 · 주간 의뢰 · 시즌 보상 · 상점 구매 · 로벅스 결제 모두. 누르면 바로 닫힙니다 |

### 분노한 해적은?

한 판에서 해적을 **16번** 잡은 사람(예전 6번)에게 다음에 나오는 해적입니다. 잡기 창이 열리지 않아서 **만나면 바로 탈락**합니다. 알림판 아래 "⚠ 분노한 해적", 칼 고르는 창 머리글 "⚠ 분노한 해적 주의" 로 미리 알려 줍니다. 판이 끝없이 이어지지 않게 하는 장치입니다 (모두가 계속 잡으면 판이 안 끝나니까요).

## 음악 올리기 (5개)

`roblox-cursed-barrel/audio/` 폴더 (GitHub 에서 받거나, 채팅으로 보내 드린 파일)

| 파일 | 넣는 곳 (`ReleaseConfig.lua` → `C.Audio`) | 무엇 |
|---|---|---|
| `lobby.ogg` | `Lobby` | 로비 뱃노래 (반복) |
| `match.ogg` | `Match` | 게임 중 긴장 음악 (반복) |

1. Studio → **보기 → 에셋 관리자** → **가져오기(Import)** → 5개 선택
   - 또는 create.roblox.com → 작품 → **개발 아이템 → 오디오 → 에셋 업로드**
   - ⚠️ 게임을 **그룹이 가지고 있으면 그룹 이름으로** 올려야 게임에서 소리가 납니다 (내 계정으로 올린 소리는 내 게임에서만 들립니다)
   - 오디오는 한 달에 올릴 수 있는 개수가 정해져 있습니다 (계정 인증 여부에 따라 다름). 5개면 충분합니다
2. 심사(몇 분 ~ 몇 시간)가 끝나면 오른쪽 클릭 → **Copy Asset ID**
3. `ReleaseConfig.lua` 의 `C.Audio` 에 숫자를 넣습니다 : `Lobby = 1234567890,`
   - `Night` · `Storm` 은 0 으로 두면 밤 · 폭풍에도 뱃노래가 나옵니다
- 음악 크기는 설정 → 음악(기본 35%)을 따릅니다
- 곡을 바꾸고 싶으면 `audio/compose.py` 의 가락 · 빠르기를 고치고 `python3 audio/compose.py` (말씀만 해 주셔도 됩니다)

## 업데이트 올리기 — 다시 출시할 필요 없습니다 (덮어쓰기)

게임을 새로 만들면 안 됩니다 (좋아요 · 방문 수 · 저장된 코인이 새 게임으로 안 넘어갑니다). **같은 게임에 덮어쓰면** 됩니다.

1. Studio 에서 새 파일(`CursedBarrel_Phase21_Music.rbxl`) 열기
2. **파일 → Roblox에 다른 이름으로 게시(Publish to Roblox As…)**
3. 목록에서 **기존 게임 "해적 통 아저씨 잡기"** 고르기 → 그 안의 장소(시작 장소) 고르기 → **덮어쓰기(Overwrite)**
   - 이름 · 아이콘 · 좋아요 · 방문 수 · 상품 · 플레이어 저장 데이터(코인 · 스킨)는 그대로입니다
4. 이미 켜져 있는 서버는 예전 버전으로 돕니다. create.roblox.com → 이 게임 → **⋯ → 서버 다시 시작(Restart Servers)** 을 누르면 모두 새 버전으로 옮겨 갑니다 (안 눌러도 새로 들어오는 사람은 새 버전)
- 한 번 덮어써 두면, 그 뒤로 이 파일을 열었을 때는 **파일 → Roblox에 게시** 만 눌러도 같은 게임에 올라갑니다
- ⚠️ Studio 에서 직접 바꾼 것(블렌더 모델 · 해적 모델 · ID)이 있으면 **다음에 저에게 파일을 보내기 전에 파일 → 파일로 저장** 해서 그 파일을 보내 주세요. 제가 그 파일 위에 고칩니다 (예전 파일에 고치면 직접 바꾼 것이 사라집니다)

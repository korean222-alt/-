# 새 채팅용 프롬프트: "작은 행성 걷기" 시험판

> 아래 **복사할 프롬프트** 부분을 새 채팅 첫 메시지에 그대로 붙여 넣는다.
> (둥근 언덕 시험판 dometest 는 "그냥 언덕" 느낌이라 원하던 게 아니었다 → 진짜 행성으로 시험)

---

## 복사할 프롬프트

```text
나는 Roblox 게임 WILDHOLD 를 만들고 있는 초보자야. 설명은 쉬운 한국어로 해줘.
저장소 korean222-alt/- 의 브랜치 claude/trusting-keller-sbxpz0 에서 작업해줘.

이번에도 본 게임이 아니라 "되는지만" 확인하는 작은 시험판이야.
wildhold/ 폴더, WILDHOLD.rbxlx, dometest/ 는 건드리지 마.
새 폴더 planettest/ 에 따로 만들고, 결과 파일은 planettest/PlanetTest.rbxlx 하나로 줘.

■ 원하는 느낌
게임 "Messenger" 처럼 아주 작은 공 모양 행성 위를 걷는 것.
- 어느 방향으로 걸어도 발밑 땅이 계속 둥글게 이어지고, 쭉 걸으면 한 바퀴 돌아 제자리로 온다
- 지평선이 둥글게 휘어서, 멀어지는 물건은 지평선 뒤로 가라앉고 다가가면 솟아오른다
- 중력은 항상 행성 중심을 향한다 (행성 반대편에 서 있는 다른 사람은 거꾸로 보임)
전에 "둥근 언덕"(보통 중력 + 언덕 꼭대기)으로 시험했는데 그냥 언덕이라 원하던 게 아니었어.

■ 만드는 방법 (조사해 둔 것)
- 로블록스는 기본 중력이 항상 아래라서, 플레이어 캐릭터에 "중력 방향을 바꾸는 조종기"가 필요해.
  개발자들이 많이 쓰는 건 EgoMoose 의 공개 Gravity Controller (GitHub: EgoMoose/Rbx-Gravity-Controller)를
  행성 중심 방향 중력으로 바꿔 쓰는 방식이야. 먼저 그 코드의 라이선스(상업적 사용 가능 여부)를 확인하고,
  쓸 수 있으면 출처 표기와 함께 가져와 쓰고, 아니면 필요한 부분만 직접 짜줘.
- 알려진 문제: 경사진 물체에 캐릭터가 달라붙음, 카메라 흔들림·뒤집힘, 휴대폰 조작.
  중력 방향은 "발밑 표면"이 아니라 항상 "행성 중심"으로 계산해서 달라붙는 문제를 피하고,
  카메라도 행성 기준 위쪽을 따라가게 해줘.
- 행성 땅은 Terrain 이 아니라 공 모양 메쉬나 파트로 (Terrain 은 공 모양 중력에 안 맞음).
- 괴물처럼 스스로 움직이는 것은 물리 대신 계산으로 움직여줘 (행성 표면을 따라 대원 경로로 이동).
  본 게임도 펫·괴물을 보이지 않는 기준 파트 + 계산으로 움직이니까 나중에 옮기기 쉽게.

■ 시험판에 넣을 것 (이것만)
1. 작은 행성: 반지름 같은 숫자는 파일 맨 위 설정 한 곳에 모아서 내가 바꿔 다시 시험할 수 있게.
   시작값 추천도 해줘 (한 바퀴 도는 데 1~2분 정도 걸리는 크기).
2. 플레이어: 행성 위 걷기, 점프, 한 바퀴 돌기. 기본 로블록스 아바타 그대로. 컴퓨터·휴대폰 둘 다.
3. 카메라: 행성 위 어디서든 자연스럽게 따라오고 뒤집히지 않게.
4. 행성 위 물건: 모닥불 기지 하나, 나무 여러 그루, 바위 몇 개, 거리 비교용 깃발 몇 개.
   저장소 assets/env/EnvModels.fbx (숲 키트)를 ReplicatedStorage.EnvModels 로 넣었을 때 쓰고,
   없으면 간단한 파트로 대체. 모두 행성 표면에 수직으로 서게.
5. 괴물 1마리: 행성 표면을 따라 기지로 걸어왔다가 돌아가기를 반복 (눈이 빛나는 단순한 모양, 싸움 없음).
6. 낮/밤 전환 버튼 하나.
7. 멀티플레이 확인용: 다른 플레이어가 행성 반대편에서도 제대로(거꾸로) 보이는지.
그 밖의 것(펫, 포획, 자원, 건설, 저장, UI)은 넣지 마.

■ 작업 방식
- 코드는 짧고 단순하게. 시험이 끝나면 버릴 수도 있는 코드야.
- 저장소의 wildhold/tools/build_place.py 와 테스트 방식(wildhold/tests/)을 참고해서
  src → rbxlx 로 만들고, 헤드리스로 검사할 수 있는 건 검사해줘
  (행성 좌표 계산, 물건이 표면에 서 있는지, 괴물이 표면을 따라 움직이는지, 한 바퀴 이동 계산).
- 캐릭터 물리·카메라 느낌은 로블록스에서만 확인되니까, 내가 Studio 에서 걸어보고 이상한 점을 알려주면
  고치는 식으로 2~3번 반복할 거야. 처음부터 "완벽하다"고 하지 말고, 확인 못 한 부분을 솔직하게 적어줘.
- 끝나면 planettest/시험_방법.md 에 Studio 에서 확인할 순서와 체크리스트
  (걷기·점프·한 바퀴·카메라·경사진 물체·휴대폰 에뮬레이터·2인 테스트), 숫자 바꾸는 방법,
  문제가 생기면 나한테 어떤 정보(출력 창 빨간 줄, 스크린샷, 어디서 무슨 일)를 보내면 되는지 적고,
  커밋·푸시한 뒤 PlanetTest.rbxlx 를 보내줘.
```

## 참고 (사람이 읽는 부분)

- 목적: 진짜 작은 행성 걷기가 로블록스에서 **자연스럽게 되는지** Studio 에서 직접 걸어보고 판단
- 처음부터 완벽하지 않을 수 있다. 이상하면 **출력 창의 빨간 줄 + 스크린샷 + 어디서 무슨 일이 있었는지**를 새 채팅에 보내서 고친다 (2~3번 예상)
- 느낌이 좋으면 → 본 게임(WILDHOLD)을 행성으로 옮기는 큰 작업을 따로 계획한다
- 별로면 → planettest 폴더를 지우면 끝. 본 게임은 그대로다

# 새 채팅용 프롬프트: "둥근 언덕 맵" 시험판

> 아래 **복사할 프롬프트** 부분을 새 채팅 첫 메시지에 그대로 붙여 넣는다.

---

## 복사할 프롬프트

```text
나는 Roblox 게임 WILDHOLD 를 만들고 있는 초보자야. 설명은 쉬운 한국어로 해줘.
저장소 korean222-alt/- 의 브랜치 claude/trusting-keller-sbxpz0 에서 작업해줘.

이번에는 본 게임을 고치는 게 아니라, 아이디어 하나가 "되는지만" 확인하는 아주 작은 시험판을 만들 거야.
기존 wildhold/ 폴더와 WILDHOLD.rbxlx 는 절대 건드리지 마.
새 폴더 dometest/ 에 따로 만들고, 결과 파일은 dometest/DomeTest.rbxlx 하나로 줘.

■ 확인하고 싶은 것
게임 "Messenger" 처럼 작은 행성 위를 걷는 느낌을 원했는데, 진짜 행성(중력 방향을 바꾸는 방식)은
로블록스에서 오류 없이 만들기 어려워서 포기했어. 대신 이걸 시험해:
- 기지를 아주 크고 완만한 "둥근 언덕(공의 윗부분)" 꼭대기에 둔다
- 걸어 나갈수록 땅이 공처럼 아래로 휘어서, 멀어지면 기지가 지평선 뒤로 가라앉고
  돌아오면 기지(모닥불)가 언덕 위로 솟아오르는 느낌이 나는지
- 언덕 가장자리에서 걸어오는 괴물이 지평선 너머에서 "머리부터" 솟아오르며 보이는지
- 로블록스 기본 중력·기본 캐릭터·기본 카메라를 그대로 쓴다 (중력이나 조작을 직접 만들지 마)

■ 시험판에 넣을 것 (이것만)
1. 둥근 언덕 지형: 공의 윗부분 모양. 반지름·놀이 범위 같은 숫자는 파일 맨 위 설정 한 곳에 모아서
   내가 숫자만 바꿔 다시 시험할 수 있게 해줘. 시작값 추천도 해줘
   (예: 공 반지름 500~700, 놀이 반지름 150 → 가장자리 경사가 너무 가파르지 않게, 걷기 편하게).
   거대한 공 전체를 Terrain 으로 채우지 말고 윗부분만 층층이 쌓는 식으로 가볍게 만들어줘.
2. 꼭대기 기지 표시: 모닥불(불빛·불꽃) 하나와 작은 말뚝 울타리 정도만. 스폰도 꼭대기.
3. 거리 표지: 기지에서 30, 60, 90, 120 stud 떨어진 곳에 눈에 띄는 기둥이나 깃발
   (지평선에 어떻게 가라앉는지 비교하려고).
4. 가장자리 숲: 언덕 가장자리를 나무로 둘러서 맵 끝을 막기. 저장소의 assets/env/EnvModels.fbx
   (숲 키트)를 ReplicatedStorage.EnvModels 로 넣었을 때 쓰고, 없으면 간단한 파트 나무로 대체.
   모든 물건은 둥근 땅 높이에 맞춰 세우고, 경사면에서는 살짝 묻어서 공중에 뜨지 않게.
5. 걸어오는 괴물 1마리: 가장자리에서 꼭대기 기지까지 땅을 따라 천천히 걸어왔다가 다시 가장자리로
   돌아가기를 반복. 눈이 빛나는 단순한 모양이면 충분. 싸움·체력·AI 는 필요 없어.
6. 낮/밤 전환 버튼 (화면 구석 버튼 하나): 밤에 모닥불만 밝을 때 지평선 느낌이 어떤지 보려고.
그 밖의 것(펫, 포획, 자원, 건설, 저장, UI)은 넣지 마.

■ 작업 방식
- 저장소의 wildhold/tools/build_place.py 와 테스트 방식(wildhold/tests/)을 참고해서
  dometest 도 src → rbxlx 로 만들고, 가능하면 헤드리스로 "지형 생성·물건이 땅 위에 서 있음·
  괴물이 땅을 따라 움직임" 정도는 검사해줘.
- 코드는 짧고 단순하게. 시험이 끝나면 버릴 수도 있는 코드야.
- 끝나면 dometest/시험_방법.md 에 내가 Studio 에서 확인할 순서와 체크리스트,
  숫자를 바꿔 다시 시험하는 방법을 적고, 커밋·푸시한 뒤 DomeTest.rbxlx 를 보내줘.
- 로블록스를 직접 실행할 수 없어서 확인 못 한 부분이 있으면 솔직하게 알려줘.
```

## 참고 (사람이 읽는 부분)

- 이 시험의 목적: "둥근 언덕" 방식이 Messenger 같은 느낌을 주는지 **Studio 에서 직접 걸어보고** 판단하기
- 느낌이 좋으면 → 본 게임(WILDHOLD) 맵을 둥근 언덕으로 옮기는 작업을 따로 한다
- 느낌이 별로면 → dometest 폴더를 지우면 끝. 본 게임은 그대로다

## 1. 게임 한 줄

약한 펫을 잡아 팀을 꾸리고, 더 강한 야생 펫을 약화·포획한다. 밤에는 그 펫 팀과 방어 시설로 기지(Core)를 지키는 **협동 생존** 게임 (Roblox, Luau).
원래 기획서: `WILDHOLD_Game_Design_v4_Pet_Centered.md` (사용자가 가지고 있음). 외부 에셋 조사 문서: `WILDHOLD_Asset_Research_and_Pet_Production.md`.

## 3. 지금까지 한 일

### 3.1 1~8단계 다시 만들기 (완료)
- GPT 가 만든 원본(회색 판자 + 떠 있는 글씨)의 **서버 로직은 유지**하고 보이는 것 전부를 새로 만들었다.
  (포획 → 우리 등록 → 밤 생존 → 영구 확정, DataStore 세션 잠금 저장, 서버 권한형)
- 맵: 지형, 말뚝 울타리 기지, 3 길목 + 괴물 굴, 연못, 알파의 숲, 자원 노드 모델, 레벨별 방어 시설 모델
- 크리처: 서버는 보이지 않는 기준 파트만 움직이고 클라이언트가 모델을 붙여 절차적 애니메이션
- 효과: 속성별 공격, 포획 바구니 3회 흔들림, 건설 먼지, 괴물 연기, 드랍 자원 둥실
- UI: 낮/밤 알약 + 타이머 + Core 체력, 목표 카드, 출전 펫 3칸(3D 얼굴), 배너, 결과 화면, 펫 패널 재디자인
- 버그 수정: 포탑이 앞 벽에 시야가 막혀 벽을 치는 적을 못 쏘던 문제

### 3.2 블렌더 펫 4종 (완료, 단 "새끼/귀여움" 톤)
- `wildhold/blender/` 파이썬 스크립트로 SDF 조각 → 텍스처 베이크 → 리깅 → FBX
- 모슬링, 엠버펍, 셸버브, 브라이어혼 α. 삼각형 7~10k, 뼈 10~12개
- 사용자 피드백: 너무 귀엽다. **성장형의 새끼 단계로 두고, 성체는 Meshy 로 사나운 디자인을 새로 만든다**

### 3.3 생존 톤 전환
- `EnvironmentController`: 평범하게 밝은 낮 / 붉은 노을 / 짙은 안개 밤(가시거리 짧음, 채도 낮춤) / 새벽. 노을·밤에 모든 캐릭터에 등불, 횃불·모닥불 깜빡임
- 지형 색 어둡게, 숲 경계를 키 큰 전나무 두 줄로, 안쪽에 죽은 나무·쓰러진 통나무·빛나는 버섯 (꽃 제거)
- Core: 제단 위 **성스러운 모닥불**(밤에 기지를 비추는 큰 불빛) + 그 위에 떠 있는 수정
- 괴물 몸을 더 어둡게, 눈을 더 크게 (안개 속에서 눈부터 보이게)
- 검증: `selene src` 오류 0 (기존 경고 3개), `./tests/run.sh` **모든 검사 통과**, `WILDHOLD.rbxlx` 재생성 완료
- README 맵 사진 3장을 생존 톤 낮 모습으로 교체. (`render_scene.py` 는 월드 안개를 빼서 한 장에 약 4분,
  장면 내보내기는 테스트용 가짜 블렌더 펫(MeshPart)을 빼서 회색 상자가 안 찍히게 함)

### 3.4 사실적인 숲으로 전환 (이번 채팅 마지막 작업)
- 사용자 피드백: 맵 미리보기가 "완전 평화로워 보인다, 동물의 숲급". 원인 = 솜사탕 모양 나무, 파스텔 색, 텅 빈 초원, 밝은 낮
- **블렌더 숲 키트** `blender/env_kit.py` → `assets/env/EnvModels.fbx` (+ `.blend`, 에셋별 png, `sizes.lua`)
  - 가문비나무 3종(3.4~4k 삼각형) + 뒷줄용 가벼운 가문비나무 2종(1.4k), 고사목 2, 바위 4(둥근 바위·납작 바위·바위 기둥), 쓰러진 통나무, 그루터기, 고사리
  - 나무껍질 틈·지의류·이끼·솔잎 결·나이테를 절차적 셰이더로 텍스처 한 장에 굽고 AO 를 곱함. 모두 닫힌 메쉬(뒷면 안 보임 문제 없음)
  - 외부 무료 에셋(Poly Haven, ambientCG)은 이 작업 환경에서 네트워크가 막혀 있어서 직접 만들었다
- 게임 연결: `Props.lua` 가 `ReplicatedStorage.EnvModels` 를 찾아 메쉬를 쓰고, 없으면 예전 파트 모델로 대체. 작업 공간에 두면 자동으로 옮김
- 맵: 숲 벽 3줄(뒷 2줄은 가벼운 메쉬), 안쪽에 가문비나무 무리 16곳(줄기 충돌 있음) + 고사목·통나무·그루터기·바위·고사리 약 100개, 숲 바닥 얼룩(낙엽 흙·진흙)
  - 맵 파트 4,463 → 약 2,400 개 + 메쉬 약 600 개
- 색: 지형 올리브·흙색, 기지 나무를 비바람에 바랜 회갈색, 빨간 지붕·밝은 깃발·크림색 표지판 제거, 열매 덤불도 짙게
- 조명: 낮을 흐리고 서늘하게 (채도 -0.22, 안개 0.4)
- 테스트: 가짜 EnvModels 를 넣고 "숲 키트 14종 모두 사용", "작업 공간 → ReplicatedStorage 이동", "에셋 없을 때 파트 대체" 검사 추가. 모의 엔진 Random 의 하위 비트 편향도 고침
- 미리보기: `render_scene.py` 가 실제 블렌더 에셋 + 안개 + 밤 사진(`map_night.png`)까지 찍는다. 숲 키트 단체 사진 `docs/images/env_kit.png`

### 3.5 숲 키트·펫 Studio 가져오기 성공 (2026-09-29)
- 사용자가 Studio 에서 `EnvModels.fbx` 가져오기 성공. 처음엔 `base_color_texture 업로드 실패` → **한글 경로(OneDrive/Desktop/생존게임)가 원인, 영어 경로로 바꾸니 됨**
- 사용자가 보낸 rbxlx 에서 `EnvModels`(MeshPart 14개, 모두 MeshId + TextureID 있음)와 메쉬 데이터(SharedStrings)를 뽑아 `assets/env/EnvModels.rbxmx` 로 저장
- `tools/build_place.py` 가 이 파일을 `ReplicatedStorage/EnvModels` 로 넣는다 → place 를 다시 만들어도 숲 키트 유지
- 펫 FBX 4종도 가져오기 성공. 사용자가 모델을 작업 공간에 둔 채 저장해서 게임에서는 대체 모델이 쓰이고 있었다
  → 4종(MeshPart + 뼈, 메쉬·텍스처 업로드 완료)을 뽑아 `assets/pets/PetModels.rbxmx` 로 저장, `build_place.py` 가 `ReplicatedStorage/PetModels` 에 넣는다
- 안전장치: 서버 시작 때 작업 공간에 펫 종 이름의 Model(뼈 포함)이 있으면 `PetModels` 로 옮긴다 (`ServerMain`). 테스트 "펫 모델 작업 공간 → PetModels 로 옮김" 추가
- 시작 안내: 출발 대기 중 목표 카드에 "손에 든 창으로 사냥·채집" 표시 (사용자가 "기본템(도끼) 없어?" 라고 물음 — 창이 공격·채집을 둘 다 한다는 게 안 보였음)

### 3.6 생존 제작·넓은 맵·성장형·빠른 시작 (2026-09-29)
- **창이 안 보이던 문제**: CharacterAdded 가 캐릭터가 작업 공간에 들어가기 전에 와서 장착을 건너뛸 수 있었다 → 캐릭터가 들어갈 때까지 기다리고,
  `CraftingService:Sync` 가 0.5초마다 "가진 것 = Backpack 의 Tool" 을 맞춘다 (도구가 빠질 수 없음)
- **핫바** `HotbarController`: 화면 아래 1~9칸, 키·휠·터치, 체력·배고픔 막대, 기본 Backpack/Health 표시 끔. 공격 버튼 글자가 든 것에 맞게 (공격/먹기/덫 던지기/간식 주기)
- **아이템** `ItemConfig`: 창·도끼·곡괭이·횃불(등급 1~4), 덫 3종, 간식, 음식(열매·구운 버섯·스튜), 가방 2종. 모양은 `Visuals/ToolLook`
- **제작** `RecipeConfig` + `CraftingService`: 제작대 Lv1~3(팀 공용 업그레이드), 모닥불 요리. 방어 시설 Lv2·3 강화는 제작대 Lv2·3 필요
- **채집**: 도끼→나무, 곡괭이→돌·고철·수정(수정은 고철 곡괭이부터). 맞는 도구·높은 등급일수록 빠르고 많이. 창고에 넣을 때 열매 5개는 가방에 남김
- **배고픔** `SurvivalService`: 약 7분에 100→0, 0이면 체력이 20까지만 닳음
- **맵** `MapConfig` + `MapService` 새로 작성 + `Modules/Zones`: 지름 약 1500, 지역 4개, 지역별 노드·야생 펫(멀수록 레벨↑, 잡히면 90초 뒤 다시 나타남), 굴 너머 오솔길, 지역 입구 이정표, 늪 연못 여러 개, 협곡 바위 언덕.
  자리 겹침 검사는 격자(32 stud)로. `Workspace.StreamingEnabled` (클라이언트는 가까운 곳만), 기지 모델은 Persistent
- **UI**: 지역 이름 + 기지(또는 목표)까지 거리·방향 표시, 새 지역에 들어가면 배너, 노란 목표 표시(첫 판: 야생 모슬링 → 펫 우리 → 나무 → 창고)
- **성장형**: `PetConfig.EvolveLevel = 6` 이 되면 성체(Stage 2)로 진화 (체력·공격 증가, 1.25~1.5배 크기, 이름 바뀜). 야생도 Lv6 이상은 성체.
  성체 모델: `PetModels/<종>_Adult` 가 있으면 그것, 없으면 새끼 모델을 키움. 저장 `Version = 3` (Stage 필드)
- **새 펫 3종**(파트 대체 모델): 이끼사슴(풀·돌격, 고목의 숲), 애쉬리자드(불·범위, 바위 협곡), 보그토드(물·원거리, 늪). 성체 이름 고목사슴왕·용암드레이크·늪군주

### 3.9 번역 4개 언어 · 배경음악 · 효과음 · ⚙ 설정 (2026-09-30 저녁)
- **번역 구조** `Modules/Locale` + `Shared/Locale/{en,ko,es,pt}.lua` (키 421개, 키 → 문장, `{name}` 자리표시자)
  - 서버는 언어를 모른다: 글자 대신 **메시지** `L.M("키", {값})` 를 보내고 (`Notify`, 목표 카드, 목표 이름, 결과 사유, 캡처 이름…), 각 화면이 `L.text` 로 그 사람 언어로 바꾼다
  - 서버가 만든 글자(프롬프트 ActionText/ObjectText, 간판, 도구 ToolTip)는 `L.tag(obj, "Text", 메시지)` → 속성 `L_Text` 에 저장 → 클라이언트 `L.watch` 가 번역 (+ AutoLocalize 끔)
  - 클라이언트 고정 글자는 `L.bind(obj, 키)` → 언어가 바뀌면 다시 채움. 창은 `L.onChanged` 로 다시 그림
  - Config 의 한국어 `Name`/`Desc`/`Labels` 는 없앴다 → `item.<id>`, `species.<id>`, `adult.<id>`, `trait.<id>`, `traitDesc.<id>`, `role.<Role>`(Role 값은 영어 id), `res.<id>`, `perk.<id>`, `zone.<id>`, `defense.<id>`, `egg.<id>`

  - 언어 선택: 플레이어 속성 `Lang`(⚙ 설정, 저장) → 없으면 `LocalizationService.RobloxLocaleId` → `player.LocaleId`. 지원 안 하는 언어는 영어. Kick 글자는 서버에서 `L.of(player)` 언어로
  - 검사 `python3 tools/check_locale.py` (키·자리표시자·코드가 쓰는 키·Config id·코드에 남은 한국어), `tools/find_korean.py`
- **저장 설정** `profile.Settings = {Lang, Music, Sfx}` (Version 4 그대로, 없으면 {}). `Settings` 리모트 → `DataService:SetSetting` → 속성 `Lang`/`MusicVolume`/`SfxVolume`
- **⚙ 설정 창** `client/SettingsController` (왼쪽 위 ⚙): 언어(자동·English·한국어·Español·Português) · 🎵 음악 · 🔊 효과음 크기 (10단계)

**숲 키트 연결 규칙**
- `ReplicatedStorage/EnvModels` 안에서 에셋 이름(`Spruce1`, `Boulder2` …)으로 찾는다 (한 겹 더 감싸져 있어도 됨)
- 크기는 종류별 목표 높이(stud)로 맞추고, 가져온 파트가 회전돼 있어도 월드 위쪽 기준으로 계산. 원점은 bbox 중심 기준
- 메쉬마다 `EnvAsset` 속성에 에셋 이름을 남긴다 (테스트·미리보기가 사용). 나무는 줄기에만 보이지 않는 충돌 기둥
- 새 에셋 추가: `env_kit.py` 의 `ASSETS` 에 넣고 → `python3 blender/env_kit.py --render` → `Props.lua` 에서 사용

**펫 모델 연결 규칙 (Meshy 모델을 넣을 때 중요)**
- Studio 에서 가져온 모델을 `ReplicatedStorage/PetModels/<종ID>` 에 넣으면 `CreatureController` → `Rig.fromMesh` 가 사용한다. 없으면 `Creatures.lua` 파트 대체 모델
- 크기: `PetConfig.Heights[종]` 으로 자동 맞춤. 앞 방향: `Front` 또는 `Head` 뼈와 `Body` 뼈 위치로 자동 판별
- 애니메이션: `Anim.lua` 가 **뼈 이름**(Body, Head, Neck, EarL/R, Tail/Tail1/Tail2, LegFL/FR/BL/BR …)에 포즈를 준다
- **Meshy 리그는 뼈 이름이 다를 것** → 다음 작업에서 이름 매핑 표나 AnimationController 클립 재생을 추가해야 한다 (6장)

```bash
cargo install selene --locked                # Luau 린트 (설정: wildhold/selene.toml + roblox_min.yml)
cd wildhold/tests/luaurun && cargo build --release && cp target/release/luaurun ~/.cargo/bin/   # Luau VM
cd wildhold && python3 tools/build_place.py  # rbxlx 만들기
./tests/run.sh                               # 한 판 헤드리스 테스트 (끝나면 "모든 검사 통과")
python3 tests/render_scene.py docs/images    # 테스트가 내보낸 맵을 Blender 로 렌더 (낮 3 + 밤 1, 약 15분. --fast 는 빠른 확인용)
python3 tests/render_scene.py docs/images --shots=build,lobby   # 건축 가까이 + 로비 캠프만 (약 4분)
python3 blender/env_kit.py --render          # 숲 키트 다시 만들기 (약 3분) + docs/images/env_kit.png
python3 blender/build_kit.py --render        # 건축 키트 다시 만들기 (약 15분) + Config/KitSizes.lua + docs/images/build_kit.png
python3 tests/render_map.py                  # 테스트가 내보낸 지도 격자 → map_full.png / map_explored.png
```
- `tests/api.lua` 는 `npm pack @rbxts/types` 후 `tests/gen_api.py` 로 다시 만들 수 있다
- 이 환경에서 `meshy.ai`, Poly Haven, ambientCG 는 네트워크로 막혀 있다 (npm·pypi·GitHub 는 됨). Higgsfield 커넥터는 연결돼 있지만 크레딧 0.19 (무료) 이고, 그쪽 자동 리깅은 사람형 전용

## 7. 아직 확인 못 한 것

- 실제 Roblox Studio 플레이 (숲 키트·펫 가져오기는 성공 확인). 이번 변경(핫바·넓은 맵·스트리밍)은 헤드리스 테스트로만 확인
- 휘두르기: Motor6D.Transform 을 Stepped 에서 덧입히는 방식은 Studio 에서 아직 못 봄 (안 움직이면 PreSimulation/RenderStepped 로 바꿔 보기)
- 미니맵: 다 돌아다니면 Frame 이 수천 개가 될 수 있다 (한 줄에서 같은 색을 묶어도). 휴대폰에서 느리면 `MapCell` 을 24 로
- 모바일 성능: 서버 파트 약 1.4만 + 메쉬 약 4천 (클라이언트는 스트리밍으로 반경 약 500 안만). 버벅이면 `BuildScenery` 의 숫자를 줄이거나 `StreamingTargetRadius` 를 낮춘다
- 생존 톤 조명(안개 농도, 밤 밝기)이 실제 화면에서 너무 어둡거나 밝은지 → Studio 에서 보고 `EnvironmentController` 의 `LOOKS` 값만 조절하면 된다
- 게시 서버 DataStore 저장/재접속
- **텔레포트 (로비 ↔ 원정)**: Studio 에서는 안 돼서 같은 서버 안에서 흉내만 냈다. 실제 서버에서 ReserveServer · TeleportAsync · 저장 잠금 넘기기 확인 필요
- 건축 키트 메쉬를 Studio 에서 가져온 모습 (앞 방향, 크기), 도구 메쉬 Grip
- 설치 미리보기(BulkMoveTo · Highlight AlwaysOnTop)와 ⟳ 버튼 위치가 휴대폰에서 괜찮은지
- **번역 글자 길이**: 영어·스페인어·포르투갈어가 한국어보다 길어서 칸을 넘칠 수 있다 (탭·버튼은 TextScaled). Studio 에서 ⚙ 로 바꿔 보며 확인
- Roblox 자동 번역과 겹치지 않는지 (AutoLocalize 끔 + 대시보드 자동 번역 끄기 안내)

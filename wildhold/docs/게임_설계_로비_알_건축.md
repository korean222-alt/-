# WILDHOLD 설계: 로비 · 알 · 포획 전투력 · 설치형 건축

> 2026-09-30. 사용자 목표: **로비에서 방을 구해 생존 → 클리어하면 희귀한 알.** 좋은 펫은 야생에도 있고, 잡으려면 약한 여러 마리나 강한 한 마리가 필요.
> 1분 안에 재미, 소유욕과 디테일, 도구 → 작업대 → 방어물·더 좋은 도구·더 좋은 작업대.
> 사용자 선택: 알은 로비 부화장 짧은 타이머 · 실패해도 버틴 밤에 따라 보통 알 · 건축은 기지 영역 안 어디든 · 펫 디테일 4가지 모두.

## 1. 참고한 게임에서 가져온 것

| 게임 | 가져온 것 | WILDHOLD 에서 |
|---|---|---|
| **99 Nights in the Forest** | 로비의 상자에 들어가 인원(1~5)을 고르고 출발, 인원이 많을수록 어려움. 제작대 Lv1~5, 재료(나무·고철)로 레벨업, 벽·덫 같은 방어물 | 로비 **원정 수레** (정원 1~6), 혼자면 괴물 체력 0.8배 (기존). 제작대 Lv1~3, 벽·문·포탑·함정 설치 |
| **ARK** | 기절시켜 길들이기, 길들이기 효율, 인벤토리에서 제작해 구조물을 원하는 곳에 설치 | **도구로는 HP 60%까지만** → 펫이 약화, 설치 도구를 들고 미리보기로 설치 |
| **Palworld** | 포획 확률 = (구체 포획력 − 레벨)^9 × HP 계수 → 강한 상대는 준비가 필요 | **포획 확률 × (팀 전투력 / 야생 전투력)^1.3**, 0.45 미만이면 불가 |
| **포켓몬** | 개체값(같은 종이라도 능력치가 다름), 이로치(1/4096, 알은 더 잘 나옴), 성격, 알 부화, 이름 짓기 | **재능 별 1~5**, **빛나는 변종**(야생 1/200 · 보통 알 1/60 · 희귀한 알 1/25), **특성 6종**, 부화장, 이름 짓기 |
| **Adopt Me / 펫 시뮬** | 알 등급별 확률표, 부화 연출, 로비에서 펫이 따라다님 | 보통/희귀 알 확률표(EggConfig), 흔들리다 깨지는 연출, 로비에서 출전 펫 3마리가 따라다님 |

## 2. 한 판의 흐름 (1분 안에 놀기)

1. 접속 → **로비 캠프** (해 질 녘 모닥불). 화면 아래 큰 **▶ 혼자 바로 출발** (1.5초 뒤 출발) 또는 북쪽 **원정 수레**에 올라타기
2. 수레: 첫 대원 = 방장 → 정원 1~6 / 지금 출발. 다 차면 4초, 아니면 20초 뒤 모인 인원으로 출발
3. 원정 (예약 서버): 4초 뒤 낮 1. 노란 표시 → 야생 모슬링 사냥(펫이 약화) → 포획 → 펫 우리 등록
4. 🪓 나무 한 그루(나무 8) → 🔨 제작 버튼 → **제작대 설치 도구** → 들고 공격 버튼으로 설치 (**첫 건축까지 1~2분**)
5. 제작대 [F] → 벽·문·포탑·함정·배치대·횃불대 설치 도구 → 길목에 설치 / 돌·고철·수정 도구 / 제작대 [E] 강화 Lv2·3
6. 밤: 괴물이 길을 막은 벽을 부수며 온다. 포탑·펫·플레이어가 막는다
7. 5밤 클리어 = 🌟 **희귀한 알**, 3밤 이상 = 🥚 **보통 알** → 결과 화면 20초 뒤 **로비로**
8. 로비 부화장에 알 넣기(보통 1분 30초 · 희귀 3분, 실제 시각이라 원정 중에도 흐름) → 깨우기 → 부화 연출 → 이름 짓기 → 출전 팀 → 다시 출발

## 3. 규칙 (숫자는 모두 Config)

### 포획 전투력 (`PetConfig`, `PetRules`)
- 전투력 = 체력 × 0.25 + 초당 피해 × 2 (재능 별·특성·레벨·성장 단계 반영)
- **도구로는 야생 펫 HP 를 60% 아래로 못 깎는다** (`HuntFloor`). 더 치면 "펫으로 약화하세요" 안내, 공격은 옆 나무·돌로 넘어감
- 우리 팀 = 내 출전 펫 전부 + 같은 야생 펫을 사냥 중인 동료의 펫 (40m 안)
- 포획 확률 × clamp((팀/야생)^1.3, 0.3, 1.25). 팀/야생 < 0.45 면 덫을 던지지 않는다 ("너무 강합니다 · 우리 팀 X vs Y")
- 야생 이름표에 `⚔ 야생 vs 우리 · 해볼 만함 / 어려움 / ⚠ 너무 강함`
- 예: 시작 모슬링 1마리(약 60) vs 알파 브라이어혼(약 320) → 불가. Lv5 펫 3마리(약 240) → 어려움(확률 ×0.7)

### 개체 차이
| | 야생 | 보통 알 | 희귀한 알 |
|---|---|---|---|
| 재능 별 확률 (1~5) | 30/32/22/11/5 | 20/34/28/13/5 | 3개 이상 (45/35/20) |
| 빛나는 변종 | 1/200 | 1/60 | 1/25 |
| 특성 | 6종 중 하나 | 〃 | 〃 |
- 별 배율 0.9 / 1.0 / 1.1 / 1.22 / 1.38 (체력·공격). 예전 저장 펫은 별 2개(배율 1)로 본다
- 특성: 용감함(공격+15%) · 튼튼함(체력+20%) · 날쌤(공격 속도+12%) · 영리함(경험치+30%) · 충직함(기절 회복 2배) · 사냥꾼(야생 피해+25%)
- 이름: 최대 12자, 서버가 Roblox TextService 필터를 거친다 (**Roblox 규칙상 필수**)

### 알 (`EggConfig`)
- 보통 알: 모슬링 30 · 엠버펍 25 · 셸버브 25 · 이끼사슴 8 · 애쉬리자드 6 · 보그토드 6
- 희귀한 알: 이끼사슴·애쉬리자드·보그토드 각 22 · 엠버펍·셸버브 각 12 · **브라이어혼 10** (알파는 원래 고목의 숲 깊은 곳에서만)
- 부화장 2칸, 알 최대 20개 (넘치면 코인 40). 부화하면 새끼(성장형) · 도감 등록 · 출전 칸이 비어 있으면 자동

### 로비·방 (`LobbyConfig`, `LobbyService`)
- Place 하나: 공개 서버 = 로비, 예약 서버(`ReserveServer`) = 원정, Studio = 둘 다 한 서버에서 오감
- 출발할 때 로비가 저장을 먼저 풀고(release) 텔레포트, 원정 서버는 잠금이 풀릴 때까지 최대 24초 기다렸다 불러온다
- 원정이 끝나면 공개 서버(로비)로 텔레포트

### 설치형 건축 (`BuildConfig`, `DefenseService`, `Modules/Placement`)
- 기지 영역 = Core 에서 112m 안. 기지 건물(창고·펫 우리·모닥불·스폰·Core)과 다른 구조물과 겹치면 안 됨 (회전 사각형 겹침 검사, 서버·클라이언트 같은 규칙)
- 시작 구조물: 길목 문 2 · 벽 1 · 화살 포탑 1 (혼자서도 첫 밤)
- 손 제작: 제작대 설치 도구 = 나무 8. 제작대 근처: 벽 10 나무 · 문 8 · 포탑 15+돌 5 · 함정 8+돌 4 · 배치대 4+돌 6 · 횃불대 2+섬유 1
- 제작대 [E] 강화: Lv2 나무 40·돌 25·섬유 10 / Lv3 돌 40·고철 20·수정 5. 벽·문·포탑·함정 Lv2·3 강화는 그 레벨의 제작대 필요
- 재료: 가방 먼저, 기지 안에서는 공용 창고까지
- 다친 데 없으면 낮에 [G] 길게 → 설치 도구로 돌려받기 (다시 놓기)
- 괴물: 다음 길목 지점까지 가는 길(앞 몇 칸)을 막은 벽·문을 찾아 부딪히는 점에서 공격. 브루트는 가까운 구조물 아무거나

### 전투 손맛 · 도파민 포인트 (`PetConfig.Crit/Energy/Skills`, `BattleFeelController`)
펫 싸움이 "숫자만 줄어드는" 느낌이라 식상하다 → 매 타격·몇 초마다·몇 분마다 보상이 터지게 (포켓몬·뱀서류·로블록스 시뮬 참고)
| 주기 | 무엇 | 느낌 |
|---|---|---|
| 매 타격 | 떠오르는 피해 숫자 (내 펫은 크게) | 내가 이기고 있다 |
| 매 타격 | **치명타** 12% (+별 하나당 2%) ×1.75 → 큰 노란 "123!" + 화면 살짝 흔들림 + 소리 | 운이 터졌다 |
| 매 타격 | **상성** 풀 > 물 > 불 > 풀: "효과 굉장!" (초록) / "효과가 별로…" (회색) | 포켓몬처럼 고른 보람 |
| 3~6초마다 | **필살기 게이지** (때리면 17, 치명타 +10, 맞으면 6). 가득 차면 종별 필살기: 이름이 머리 위에 크게 + 원소색 충격파 + 빛 기둥 + 화면 흔들림. 왼쪽 팀 카드에 보라 게이지(가득 차면 노랑) | 곧 터진다는 기대감 |
| 계속 | **콤보** (2.5초 안에 이어지면) "COMBO x12", 클수록 크고 빨갛게, 10콤보마다 큰 글자 + 높아지는 소리 | 끊기기 싫다 |
| 괴물마다 | **KO!** + 경험치 구슬이 나에게 날아옴 | 수확 |
| 몇 분마다 | **LEVEL UP! Lv5** 빛 기둥 + 체력 가득 / 진화 | 성장 |
| 사냥마다 | 야생 펫이 지치는 순간 **"포획 가능!" + "🧺 지금 덫을 던지세요!"** | 결정적 순간 |

필살기: 모슬링 덩굴 채찍(단일 ×2.6) · 엠버펍 화염 폭풍(범위 10) · 셸버브 파도 내려찍기(범위 11) · 이끼사슴 뿔 돌진(단일 ×3.2) · 애쉬리자드 용암 분출(범위 12) · 보그토드 거품 난사(범위 7) · 브라이어혼 가시 폭풍(범위 14). 성체는 ×1.2
- 다음 후보: 치명타·필살기 때 **잠깐 멈춤(히트스톱)**, 펫이 쓰러질 때 슬로모션, 보스 처치 "MVP 펫" 화면, 콤보 보너스 경험치

## 4. 그래픽 (블렌더)
- `blender/build_kit.py` → `assets/build/BuildModels.fbx` (29개): 제작대 Lv1~3, 벽 Lv1~3(통나무 말뚝 → 돌 → 돌+쇠), 문 Lv1~2, 화살 포탑 Lv1~3, 가시 함정 Lv1~2, 펫 배치대, 횃불대, 알 2종, 둥지, 원정 수레,
  도구 10종(낡은/돌/고철 도끼, 돌/고철 곡괭이, 창 4등급, 횃불)
- 조각마다 재질(널빤지·통나무·돌·쇠·밧줄·천·수정…)을 나누고 절차적 셰이더를 텍스처 한 장으로 굽는다 (숲 키트와 같은 방식)
- Studio 에서 가져와 `ReplicatedStorage/BuildModels` 에 두면 코드가 자동으로 메쉬를 쓴다 (`Visuals/Kit`). 없으면 파트 대체 모델
- 앞 방향: 블렌더 +Y = Roblox 앞(-Z). 가져왔는데 제작대 뒤판·석궁 방향이 거꾸로면 `BuildConfig.KitFlip = true`

# WILDHOLD — 내가 직접 해야 할 일

코드와 모델은 준비되어 있고, 아래는 **Roblox 계정이나 Studio 가 있어야만 할 수 있는 일**이다.
순서대로 하면 된다. ⭐ 표시는 꼭 해야 하는 것, 나머지는 선택.

---

## 1. ⭐ Studio 에서 열고 플레이 (5분)

- [ ] `WILDHOLD.rbxlx` 를 Roblox Studio 로 연다.
- [ ] **파일 → 다른 이름으로 저장** 해서 내 place 로 만든다 (나중에 게시하려면 필요).
- [ ] 플레이(F5). 15초 뒤 원정이 시작된다.
- [ ] 확인할 것:
  - [ ] 맵이 보인다 (울타리 기지, 흙길 3개, 숲, 연못)
  - [ ] 출력 창(보기 → 출력)에 빨간 오류가 없다
  - [ ] 문 밖 초원의 야생 모슬링에 가서 E → 사냥 → 포획까지 된다
  - [ ] 밤에 괴물이 굴에서 나오고 포탑이 화살을 쏜다

오류가 뜨면 **출력 창의 빨간 줄을 그대로 복사해서** 알려주면 된다.

## 2. ⭐ 블렌더 펫 넣기 (3분)

받은 파일 중 `Mossling.fbx`, `Emberpup.fbx`, `Shellbub.fbx`, `Briarhorn.fbx` 를 쓴다.
(`.png` 는 텍스처, `.blend` 는 블렌더에서 고칠 때만 필요. Studio 는 `.blend` 를 직접 못 읽는다)

- [ ] 홈 → **가져오기(Import 3D)** → FBX 4개를 한꺼번에 선택
- [ ] 설정은 기본값. 리그 종류를 물으면 **Custom**, 텍스처 포함 확인 → 가져오기
- [ ] 작업 공간(Workspace)에 생긴 모델 4개를 탐색기에서 **ReplicatedStorage → PetModels** 로 끌어다 놓기 (이름 그대로)
- [ ] 플레이해서 확인:
  - [ ] 펫이 블렌더 모델로 보인다 (텍스처 색이 나온다)
  - [ ] 앞을 보고 걷는다 (뒤로 걸으면 알려주기)
  - [ ] 크기가 캐릭터 무릎~허리 정도 (브라이어혼은 캐릭터보다 큼)
  - [ ] 다리·꼬리·귀가 움직인다

## 3. 효과음 넣기 (선택, 20분)

지금은 Roblox 내장 기본 소리(칼 휘두르는 소리 등)를 임시로 쓰고 있다.

1. [ ] 무료(CC0) 효과음 받기
   - Kenney **Impact Sounds**: https://kenney.nl/assets/impact-sounds
   - Kenney **Interface Sounds**: https://kenney.nl/assets/interface-sounds
2. [ ] 아래 표를 보고 각 칸에 어울리는 소리를 하나씩 고른다 (직접 들어보고 고르는 게 제일 좋다)

   | AudioConfig 이름 | 언제 나오나 | 고를 소리 느낌 | 추천 팩 |
   |---|---|---|---|
   | `Attack` | 창 찌르기 · 채집 | 짧은 "퍽/툭" | Impact (punch, wood) |
   | `Arrow` | 포탑 화살 | 가벼운 "틱" | Impact (light) |
   | `Build` | 건설 · 수리 | 나무 두드리는 소리 | Impact (wood, plank) |
   | `Capture` | 포획 성공 | 밝은 "띠링" | Interface (confirmation) |
   | `Fail` | 포획 실패 | 낮은 "뚝" | Interface (error) |
   | `Secured` | 영구 확정 | 조금 긴 성공음 | Interface (confirmation) |
   | `Night` | 밤 시작 | 낮고 불길한 소리 | Impact (heavy) 또는 따로 |
   | `Click` | UI 버튼 | "딸깍" | Interface (click) |

3. [ ] Studio → **창 → 애셋 관리자 → 가져오기** 로 고른 `.ogg` 파일들을 올린다
   - 오디오 업로드는 계정별 월 한도가 있다 (본인 인증하면 늘어남)
4. [ ] 올린 소리를 우클릭 → **ID 복사**
5. [ ] `ReplicatedStorage → Shared → Config → AudioConfig` 를 열고 해당 칸에 붙여 넣는다
   ```lua
   Capture = "rbxassetid://여기에숫자",
   ```
   ID 만 알려줘도 내가 넣어줄 수 있다.

## 4. 여러 명 테스트 (선택, 10분)

- [ ] **테스트 탭 → 클라이언트 및 서버 → 플레이어 2~3명 → 시작**
- [ ] 두 사람이 같은 야생 펫을 동시에 사냥할 때, 먼저 때린 사람에게 포획 우선권이 가는지
- [ ] 한 명이 나가도 게임이 계속되는지
- [ ] **테스트 탭 → 기기 에뮬레이터**로 휴대폰 화면에서 버튼·글씨가 겹치지 않는지

## 5. 저장 테스트 (게시 후, 선택)

Studio 에서는 기본으로 "연습 모드"(저장 안 됨)로 돈다.

- [ ] 게임을 **비공개로 게시**
- [ ] 게임 설정 → 보안 → **Studio API 서비스 접근 허용** 켜기
- [ ] 실제 Roblox 앱에서 들어가 → 펫 잡기 → 우리 등록 → 밤 버티기 → 나갔다 다시 들어와서 펫이 남아 있는지

## 6. Higgsfield 로 3D 펫을 만들고 싶다면

- [ ] 지금 계정은 **무료 플랜, 크레딧 0.19** 라서 3D 생성을 돌릴 수 없다. 크레딧을 충전해야 한다.
- [ ] 상업 이용 조건(유료 플랜 여부)을 Higgsfield 요금제 페이지에서 확인한다.
- [ ] 충전 후 알려주면: 콘셉트 이미지 → 3D 변환 → 블렌더에서 줄이고 리깅 → FBX 순서로 한 마리 시험 제작한다.

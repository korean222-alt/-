## 3. ⭐ 플레이해서 확인 (10분) — 이번에 크게 바뀜

**2026-09-30 고친 것도 같이 확인** (도구 쥐는 법 · 휘두르기 · 나무/건물 충돌 · 모든 나무 베기 · 맵 경계 · 미니맵)
  - [ ] 🪓도끼·⛏곡괭이·🔥횃불은 **자루를 세워서** 들고, 🔱창은 앞으로 겨눠 든다. 🧺덫은 손잡이를 쥐고 매단다
  - [ ] 공격하면 도끼·곡괭이는 **머리 위로 들었다가 내려찍고**, 창은 **찌르고**, 음식은 **입으로** 가져간다 (예전: 전부 칼처럼 찌르기)
  - [ ] 나무·고사목·울타리·펫 우리·횃불·깃발·굴 바위 등을 **뚫고 지나갈 수 없다**
  - [ ] **숲의 가문비나무·고사목도 도끼로 벨 수 있다** (그루터기가 남고 45초 뒤 다시 자람)
  - [ ] 맵 끝 숲 벽에서 **더 나갈 수 없다** (보이지 않는 벽. 혹시 끼어서 밖으로 나가면 자동으로 안쪽으로 돌아옴)
  - [ ] 오른쪽 위 **미니맵**: 처음엔 기지 둘레만 그려져 있고, 걸어 다닌 곳만 그려진다 (안 가 본 곳은 빈 양피지). ▲ = 나, 🏠 기지
  - [ ] 미니맵을 누르거나 **M 키** → 큰 지도. ✕ 나 바깥을 누르면 닫힘
  - [ ] 휴대폰 화면(기기 에뮬레이터)에서 미니맵이 오른쪽 🎯사냥·🐾따라와 버튼과 겹치지 않는지
  - 참고: 컴퓨터에서 오른쪽 위를 가리던 기본 **플레이어 목록은 껐다** (미니맵 자리). 다시 켜고 싶으면 말해 주기

- [ ] 최신 `WILDHOLD.rbxlx` 를 열고 **파일 → Roblox에 저장** (기존 게임에 덮어쓰기)
- [ ] 플레이(F5). **4초 뒤 바로 원정 시작**
- [ ] 확인할 것 (스톱워치로 재 보기: **들어와서 30초 안에 뭘 할지 알겠는지**)
  - [ ] 화면 아래 **핫바**에 🔱낡은 창 · 🪓낡은 도끼 · 🧺덫 · 🍪간식이 보이고, 1~9 키나 클릭으로 바꿔 들 수 있다. **손에 든 게 보인다**
  - [ ] 핫바 위 ❤ 체력 · 🍖 배고픔 막대, 배고픔이 천천히 줄고 🍓열매를 들고 공격하면 먹는다
  - [ ] **노란 ⬇ 표시**를 따라가면 야생 모슬링 → 사냥 → 덫 → 펫 우리 순서로 안내된다
  - [ ] 🪓도끼로 나무를 치면 창보다 빨리 캔다. 제작대에서 🔥횃불·돌 도구를 만들면 핫바에 새 칸이 생긴다
  - [ ] 위쪽 가운데 "지역 이름 · 🏠 거리 화살표" 가 맞게 가리킨다. 기지 밖 멀리(🌋 북쪽 / 🌲 남동 / 💧 남서) 가 보기
  - [ ] **혼자서** 5밤을 버틸 만한지 (너무 쉽거나 어려우면 알려주기)
  - [ ] 출력 창(보기 → 출력)에 빨간 오류가 없다
  - [ ] **휴대폰에서 버벅이거나 로딩이 긴지** (테스트 탭 → 기기 에뮬레이터로도 확인)
- [ ] 스크린샷 + 느낀 점(재미없는 순간, 헷갈린 순간)을 Claude 에게 보내기

오류가 뜨면 **출력 창의 빨간 줄을 그대로 복사해서** Claude 에게 보내면 된다.

## 5. 효과음 넣기 (선택, 20분)

지금은 Roblox 내장 기본 소리(칼 휘두르는 소리 등)를 임시로 쓰고 있다. 생존 분위기에는 소리가 크게 중요하다.

1. [ ] 무료(CC0) 효과음 받기
   - Kenney **Impact Sounds**: https://kenney.nl/assets/impact-sounds
   - Kenney **Interface Sounds**: https://kenney.nl/assets/interface-sounds
2. [ ] 아래 표를 보고 칸마다 어울리는 소리를 하나씩 고른다 (직접 들어보고 고르는 게 제일 좋다)

   | AudioConfig 이름 | 언제 나오나 | 고를 소리 느낌 | 추천 팩 |
   |---|---|---|---|
   | `Attack` | 창 찌르기 · 채집 | 짧은 "퍽/툭" | Impact (punch, wood) |
   | `Arrow` | 포탑 화살 | 가벼운 "틱" | Impact (light) |
   | `Build` | 건설 · 수리 | 나무 두드리는 소리 | Impact (wood, plank) |
   | `Capture` | 포획 성공 | 밝은 "띠링" | Interface (confirmation) |
   | `Fail` | 포획 실패 | 낮은 "뚝" | Interface (error) |
   | `Secured` | 영구 확정 | 조금 긴 성공음 | Interface (confirmation) |
   | `Night` | 밤 시작 | 낮고 불길한 소리 | Impact (heavy) 또는 다른 무료 효과음 |
   | `Click` | UI 버튼 | "딸깍" | Interface (click) |

3. [ ] Studio → **창 → 애셋 관리자 → 가져오기** 로 고른 `.ogg` 파일들을 올린다 (오디오 업로드는 계정별 월 한도가 있음)
4. [ ] 올린 소리 우클릭 → **ID 복사** → Claude 에게 "Capture = 123456…" 처럼 알려주면 넣어 준다
   (직접 넣으려면 `ReplicatedStorage → Shared → Config → AudioConfig` 에 `"rbxassetid://숫자"`)

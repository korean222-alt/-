# WILDHOLD — 내가 직접 해야 할 일

> 새 채팅을 시작할 때 이 파일과 `진행상황.md` 를 함께 넣으세요.
> 코드와 모델은 Claude 가 만들고, 아래는 **Roblox 계정·Studio·Meshy 계정이 있어야만 할 수 있는 일**입니다.
> ⭐ = 꼭 해야 하는 것, 나머지는 선택. 위에서부터 순서대로.

---

## 1. ⭐ Studio 에서 열고 숲 키트 넣기 (5분)

숲 키트 = 블렌더로 만든 **사실적인 가문비나무·고사목·이끼 바위·쓰러진 통나무·그루터기·고사리** 모델 14개.
**이걸 넣어야 맵이 "동물의 숲" 이 아니라 어두운 생존 숲으로 보인다.** (안 넣으면 예전 동글동글한 파트 나무로 나온다)

- [ ] 최신 `WILDHOLD.rbxlx` 를 Roblox Studio 로 연다
- [ ] **파일 → 다른 이름으로 저장** 해서 내 place 로 만든다
- [ ] 홈 → **가져오기(Import 3D)** → `assets/env/EnvModels.fbx` **파일 하나만** 선택
- [ ] 설정은 기본값, 텍스처 포함 확인 → **가져오기**
- [ ] 작업 공간(Workspace)에 `EnvModels` 모델이 생긴다 (나무·바위가 한 줄로 서 있음)
- [ ] 탐색기에서 `EnvModels` 를 **ReplicatedStorage** 로 끌어다 놓는다 (이름 그대로)
  - 깜빡하고 작업 공간에 둬도 게임이 시작할 때 코드가 알아서 옮긴다
- [ ] 업로드 오류가 뜨면 그 문구를 그대로 Claude 에게 보내기

## 2. ⭐ 블렌더 펫(새끼 단계) 넣기 (3분)

- [ ] 홈 → **가져오기(Import 3D)** → `assets/pets/` 의 `Mossling.fbx`, `Emberpup.fbx`, `Shellbub.fbx`, `Briarhorn.fbx` 한꺼번에 선택
- [ ] 설정은 기본값. 리그 종류를 물으면 **Custom**, 텍스처 포함 확인 → 가져오기
- [ ] 작업 공간에 생긴 모델 4개를 탐색기에서 **ReplicatedStorage → PetModels** 로 끌어다 놓기 (이름 그대로)

## 3. ⭐ 플레이해서 확인 (5분)

- [ ] 플레이(F5). 15초 뒤 원정이 시작된다
- [ ] 확인할 것
  - [ ] 기지 밖이 **빽빽하고 어두운 가문비나무 숲**, 발밑에 고사리·바위·쓰러진 나무가 보인다
  - [ ] 낮은 **흐리고 서늘한 느낌**, 밤은 짙은 안개와 어둠 + 기지 모닥불·횃불만 밝다
  - [ ] 출력 창(보기 → 출력)에 빨간 오류가 없다
  - [ ] 문 밖 초원의 야생 모슬링에게 가서 E → 사냥 → 포획이 된다
  - [ ] 펫이 블렌더 모델로 보이고 앞을 보고 걷는다
  - [ ] **아직 평화로워 보이는 곳, 너무 어두운 곳, 휴대폰에서 버벅이는지** 스크린샷과 함께 알려주기

오류가 뜨면 **출력 창의 빨간 줄을 그대로 복사해서** Claude 에게 보내면 된다.

## 4. ⭐ Meshy 로 사나운 성체 펫 1마리 만들기 (30분~1시간)

- [ ] https://www.meshy.ai 에 **무료 가입** (카드 등록 필요 없음, 월 100크레딧)
- [ ] `Meshy_질문_프롬프트.md` 의 **"복사할 프롬프트"** 를 ChatGPT 같은 AI 에게 붙여 넣고, 안내를 따라 한다
  - 막히면 Meshy 화면을 스크린샷으로 찍어서 그 AI 에게 보여주기
- [ ] 첫 펫은 **신더팽(Cinderfang)** 한 마리만. 결과가 마음에 들면 다음 채팅에서 게임에 넣고, 그다음 펫으로 넘어간다
- [ ] 무료 플랜은 출처 표기가 필요하다 → 그 AI 가 알려준 **출처 문구를 메모**해 두기
- [ ] 받은 파일(모델 FBX, 동작 FBX, GLB, 텍스처 png, 원본 그림)과 그 AI 의 마지막 정리를 **새 Claude 채팅에 올리기**

크레딧이 모자라면: 다음 달까지 기다리거나, 재미가 확인된 뒤 **Pro 를 한 달만($20)** 결제해서 나머지를 몰아서 만들고 해지.

## 5. 효과음 넣기 (선택, 20분)

지금은 Roblox 내장 기본 소리(칼 휘두르는 소리 등)를 임시로 쓰고 있다. 생존 분위기에는 소리가 크게 중요하다.

1. [ ] 무료(CC0) 효과음 받기
   - Kenney **Impact Sounds**: https://kenney.nl/assets/impact-sounds
   - Kenney **Interface Sounds**: https://kenney.nl/assets/interface-sounds
2. [ ] 아래 표를 보고 칸마다 어울리는 소리를 하나씩 고른다 (직접 들어보고 고르는 게 제일 좋다)

   | AudioConfig 이름 | 언제 나오나 | 고를 소리 느낌 | 추천 팩 |
   |---|---|---|---|
   | `Attack` | 창 찌르기 · 채집 | 짧은 "퍽/툭" | Impact (punch, wood) |
   | `Arrow` | 포탑 화살 | 가벼운 "틱" | Impact (light) |
   | `Build` | 건설 · 수리 | 나무 두드리는 소리 | Impact (wood, plank) |
   | `Capture` | 포획 성공 | 밝은 "띠링" | Interface (confirmation) |
   | `Fail` | 포획 실패 | 낮은 "뚝" | Interface (error) |
   | `Secured` | 영구 확정 | 조금 긴 성공음 | Interface (confirmation) |
   | `Night` | 밤 시작 | 낮고 불길한 소리 | Impact (heavy) 또는 다른 무료 효과음 |
   | `Click` | UI 버튼 | "딸깍" | Interface (click) |

3. [ ] Studio → **창 → 애셋 관리자 → 가져오기** 로 고른 `.ogg` 파일들을 올린다 (오디오 업로드는 계정별 월 한도가 있음)
4. [ ] 올린 소리 우클릭 → **ID 복사** → Claude 에게 "Capture = 123456…" 처럼 알려주면 넣어 준다
   (직접 넣으려면 `ReplicatedStorage → Shared → Config → AudioConfig` 에 `"rbxassetid://숫자"`)

## 6. 여러 명 테스트 (선택, 10분)

- [ ] **테스트 탭 → 클라이언트 및 서버 → 플레이어 2~3명 → 시작**
- [ ] 두 사람이 같은 야생 펫을 동시에 사냥할 때 먼저 때린 사람에게 포획 우선권이 가는지
- [ ] 한 명이 나가도 게임이 계속되는지
- [ ] **테스트 탭 → 기기 에뮬레이터**로 휴대폰 화면에서 버튼·글씨가 겹치지 않는지, 밤에 너무 어둡지 않은지

## 7. 저장 테스트 (게시 후, 선택)

Studio 에서는 기본으로 "연습 모드"(저장 안 됨)로 돈다.

- [ ] 게임을 **비공개로 게시**
- [ ] 게임 설정 → 보안 → **Studio API 서비스 접근 허용** 켜기
- [ ] 실제 Roblox 앱에서: 펫 잡기 → 우리 등록 → 밤 버티기 → 나갔다 다시 들어와서 펫이 남아 있는지

## 8. 반응 확인 (올인 전에)

- [ ] 친구 2~3명에게 해보게 하고 **첫 30초에 뭘 하는 게임인지 아는지**, 밤이 무서운지/재밌는지 물어보기
- [ ] 반응을 Claude 에게 알려주면 다음에 무엇을 고칠지 같이 정한다

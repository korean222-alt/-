## 4. ⭐ 플레이해서 확인 (15분) — 이번에 크게 바뀜 (로비 · 알 · 건축)

Studio 에서는 **로비 캠프에서 시작**하고, 출발하면 같은 서버 안의 원정 맵으로 간다 (텔레포트는 게시한 게임에서만 됨 → 8번).
원정만 빨리 보고 싶으면 `GameConfig` 의 `StudioMode = "Expedition"`.

- [ ] 최신 `WILDHOLD.rbxlx` 를 열고 (3번 건축 키트를 넣었다면 그 파일에서) 플레이(F5)
- **로비 캠프** (해 질 녘, 가운데 모닥불)
  - [ ] 화면 아래 **▶ 혼자 바로 출발** 이 크게 보이고, 누르면 1~2초 뒤 원정으로 간다
  - [ ] 내 출전 펫이 로비에서 **따라다닌다** (빛나는 펫은 반짝임)
  - [ ] 북쪽 **원정 수레**에 올라타면 방장 카드(인원 1~6 · 지금 출발), 내리면 방에서 나간다. 왼쪽에 수레 목록
  - [ ] 오른쪽 🥚 부화장 · 🐾 내 펫(출전 팀 · ✏ 이름 짓기) · 🪙 보급
- **원정**
  - [ ] 야생 펫 이름표에 **★ 재능 별 · ⚔ 전투력 vs 우리 팀 · 해볼 만함/너무 강함**. 가끔 ✨ 빛나는 야생 펫
  - [ ] 창으로만 치면 **HP 60% 에서 멈추고** "펫으로 약화하세요" → 🎯 사냥 버튼으로 펫을 붙이면 25% 까지 내려간다
  - [ ] 알파(브라이어혼 α) 에게 덫을 던지면 **"너무 강합니다"** (펫을 키우거나 여러 마리로)
  - [ ] 🪓 나무 한 그루 → 오른쪽 **🔨 제작** → 🔨 제작대 설치 도구 → 들면 **초록 미리보기** → 공격 버튼으로 설치 (R / ⟳ = 돌리기, 빨강이면 이유가 나옴)
  - [ ] 제작대 가까이 **[F] 제작** → 🧱 벽 · 🏹 포탑 설치 도구 → 길목에 설치 → 밤에 괴물이 **그 벽을 부수며** 온다
  - [ ] 제작대 **[E] 강화** → Lv2 (돌 화덕) · Lv3 (쇠 틀 · 수정 등). 벽·포탑 Lv2 는 제작대 Lv2 가 있어야 된다
  - [ ] 놓은 구조물 **[G] 길게** → 설치 도구로 돌려받기 (다친 데 없을 때 · 낮)
  - [ ] 도끼·곡괭이는 세워서 들고 내려찍기, 창은 찌르기 (지난번 고친 것)
  - [ ] **전투 손맛**: 펫이 때리면 숫자가 튀어 오르고, 가끔 큰 노란 숫자(치명타)와 "효과 굉장!", 왼쪽 팀 카드의 보라 게이지가 차면 **필살기 이름 + 큰 충격파**,
        계속 때리면 오른쪽 위 **COMBO x숫자**, 괴물을 쓰러뜨리면 **KO!** 와 구슬, 레벨이 오르면 **LEVEL UP!**, 야생 펫이 지치면 **"포획 가능!"**
  - [ ] 화면 흔들림이 너무 세거나 숫자가 너무 많아 어지러우면 알려주기 (줄이기 쉬움)
- **끝나고**
  - [ ] 결과 화면에 **🎁 보상 알** (3밤 이상 보통 알 · 5밤 희귀한 알) → 20초 뒤 **로비로**
  - [ ] 부화장에 알 넣기 → (보통 1분 30초 · 희귀 3분) → **깨우기** → 흔들리다 깨지는 연출 → 🐾 내 펫에서 이름 짓기
- [ ] 출력 창(보기 → 출력)에 빨간 오류가 없다 · 휴대폰(기기 에뮬레이터)에서 버튼이 겹치지 않는다
- [ ] 스크린샷 + 느낀 점(재미없는 순간, 헷갈린 순간)을 Claude 에게 보내기

**지난번(2026-09-30 오전)에 고친 것도 같이**: 도구 쥐는 법·휘두르기 · 나무/건물 충돌 · 모든 나무 베기 · 맵 경계 · 오른쪽 위 미니맵(가 본 곳만, M = 큰 지도)

오류가 뜨면 **출력 창의 빨간 줄을 그대로 복사해서** Claude 에게 보내면 된다.

## 6. ⭐ 배경음악 · 효과음 넣기 (30분) — 코드는 준비 완료

**음악 파일을 인터넷에서 아무거나 내려받아 올리지 말 것.** 유튜브·게임 음악 등은 저작권 때문에 Roblox 가 지우거나 계정이 경고를 받는다.
가장 쉽고 안전한 방법: **Roblox 크리에이터 스토어의 무료 음악·효과음** (Roblox 가 라이선스를 사 둔 것, 어느 게임에서나 무료, 업로드 필요 없음).

1. [ ] Studio → **보기 → 도구 상자** → 위쪽 드롭다운에서 **오디오** (또는 https://create.roblox.com/store/audio )
2. [ ] 아래 표의 **검색어**로 찾아 ▶ 로 들어 보고, 마음에 들면 **점 3개(⋯) → 애셋 ID 복사**
   - 음악은 **작성자가 Roblox** 이거나 "APM Music" / "Monstercat" 인 것이 안전하다
3. [ ] 복사한 ID 들을 Claude 에게 "Day = 123…, Night = 456…" 처럼 보내면 넣어 준다
   (직접 넣으려면 `ReplicatedStorage → Shared → Config → AudioConfig` 에 `"rbxassetid://숫자"`. 음악 칸은 `{"rbxassetid://1", "rbxassetid://2"}` 처럼 여러 곡도 됨 → 차례로 재생)

**배경음악** (상황이 바뀌면 2.5초 동안 겹쳐서 자연스럽게 바뀐다. 비어 있으면 조용함)

| AudioConfig | 언제 | 검색어 (영어로) | 느낌 |
|---|---|---|---|
| `Music.Lobby` | 로비 캠프 | `campfire acoustic`, `calm adventure` | 따뜻하고 기대되는 |
| `Music.Day` | 낮 탐험 | `forest adventure`, `exploration folk` | 밝고 모험적인 (2~3곡 추천) |
| `Music.Dusk` | 밤 오기 45초 전 | `tension rising`, `suspense` | 불안해지는 |
| `Music.Night` | 밤 방어 | `battle drums`, `action tension` | 긴장감 있는 전투 |
| `Music.FinalNight` | 마지막 밤 | `epic battle`, `boss fight` | 크고 급한 |
| `Music.Victory` | 클리어 (한 번) | `victory fanfare` | 팡파르 |
| `Music.Defeat` | 실패 (한 번) | `sad defeat`, `game over` | 짧고 아쉬운 |
| `Ambience.Day` / `Night` / `Lobby` | 음악 아래 계속 | `forest birds ambience` / `night crickets` / `campfire crackle` | 주변 소리 (선택) |

| AudioConfig | 언제 | 검색어 |
|---|---|---|
| `Chop` | 도끼로 나무 | `axe chop wood` |
| `Mine` | 곡괭이로 돌·광석 | `pickaxe stone hit` |
| `Gather` | 풀·열매 뜯기 | `grass rustle`, `pluck` |
| `Attack` | 창으로 맞힘 | `spear stab`, `hit impact` |
| `Swing` | 휘두르기 | `whoosh swing` |

| `Arrow` / `Spikes` | 포탑 · 함정 | `arrow shot` / `spike trap` |
| `Build` / `Upgrade` / `Repair` / `Break` | 설치 · 강화 · 수리 · 부서짐 | `wood build hammer` / `upgrade` / `hammer` / `wood break` |
| `Craft` / `Eat` | 제작 · 먹기 | `craft complete` / `eating crunch` |
| `TrapThrow` / `Capture` / `Fail` / `Secured` | 덫 · 포획 성공 · 실패 · 영구 확정 | `throw` / `success chime` / `fail` / `save confirm` |

## 6-2. ⭐ 번역 확인 · 게임 소개 번역 (15분)

게임 안 글자는 **영어 · 한국어 · 스페인어 · 포르투갈어** 로 다 번역해 두었다 (`ReplicatedStorage → Shared → Locale`).
플레이어의 Roblox 계정 언어로 자동으로 나오고, **⚙ → 언어** 에서 바꿀 수 있다 (저장됨). 그 밖의 언어는 영어로 나온다.

- [ ] 플레이(F5) → 왼쪽 위 **⚙ → English / Español / Português** 를 눌러 로비·원정 화면, 간판, [E] 안내가 바뀌는지
- [ ] 영어·스페인어·포르투갈어에서 **글자가 칸 밖으로 넘치는 곳**이 있으면 스크린샷 보내기 (한국어보다 길다)
- [ ] 크리에이터 대시보드 → 내 게임 → **현지화(Localization)**
  - **자동 번역 · 자동 텍스트 캡처(Automatic text capture) 설정이 켜져 있으면 꺼 두기** (이미 직접 번역했으므로. 코드도 우리 화면의 AutoLocalize 를 끈다)
  - 게임 **이름·설명**을 언어별로 넣기 → 외국 플레이어가 검색에서 찾는다 (문구는 Claude 에게 달라고 하면 만들어 준다)
- 문장을 고치거나 언어를 더 넣고 싶으면 Claude 에게 말하기 (일본어·인도네시아어 등). 검사: `python3 tools/check_locale.py`

## 8. ⭐ 게시해서 로비 → 원정 텔레포트 확인 (게시 후, 15분)

로비와 원정은 **같은 Place 하나**다 (공개 서버 = 로비, 로비가 만든 예약 서버 = 원정). 텔레포트는 게시한 게임에서만 된다.

- [ ] 게임을 **비공개로 게시** (파일 → Roblox에 저장)
- [ ] 게임 설정 → 보안 → **Studio API 서비스 접근 허용** 켜기 (저장용)
- [ ] 실제 Roblox 앱에서 들어가기 → 로비 캠프가 나온다 (원정 맵은 없어야 함)
- [ ] ▶ 혼자 바로 출발 → 몇 초 로딩 뒤 원정 서버 → 펫·코인·알이 그대로
- [ ] 원정이 끝나면 로비로 돌아온다 → 알이 부화장 목록에 있다 → 나갔다 다시 들어와도 펫·알이 남아 있다
- [ ] 친구와 같은 수레에 타서 함께 출발 (같은 원정 서버로 가는지)

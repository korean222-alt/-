  - 거꾸로면 `ReplicatedStorage → Shared → Config → BuildConfig` 에 `KitFlip = true,` 한 줄 추가 (또는 Claude 에게 말하기)

## 4. ⭐ 플레이해서 확인 (15분) — 이번에 크게 바뀜 (로비 · 알 · 건축)

Studio 에서는 **로비 캠프에서 시작**하고, 출발하면 같은 서버 안의 원정 맵으로 간다 (텔레포트는 게시한 게임에서만 됨 → 8번).
원정만 빨리 보고 싶으면 `GameConfig` 의 `StudioMode = "Expedition"`.

- [ ] 최신 `WILDHOLD.rbxlx` 를 열고 (3번 건축 키트를 넣었다면 그 파일에서) 플레이(F5)
- **로비 캠프** (해 질 녘, 가운데 모닥불)
  - [ ] 화면 아래 **▶ 혼자 바로 출발** 이 크게 보이고, 누르면 1~2초 뒤 원정으로 간다
  - [ ] 내 출전 펫이 로비에서 **따라다닌다** (빛나는 펫은 반짝임)
  - [ ] 북쪽 **원정 수레**에 올라타면 방장 카드(인원 1~6 · 지금 출발), 내리면 방에서 나간다. 왼쪽에 수레 목록
  - [ ] 오른쪽 🥚 부화장 · 🐾 내 펫(출전 팀 · ✏ 이름 짓기) · 🪙 보급
- **원정**
  - [ ] 야생 펫 이름표에 **★ 재능 별 · ⚔ 전투력 vs 우리 팀 · 해볼 만함/너무 강함**. 가끔 ✨ 빛나는 야생 펫
  - [ ] 창으로만 치면 **HP 60% 에서 멈추고** "펫으로 약화하세요" → 🎯 사냥 버튼으로 펫을 붙이면 25% 까지 내려간다
  - [ ] 알파(브라이어혼 α) 에게 덫을 던지면 **"너무 강합니다"** (펫을 키우거나 여러 마리로)
  - [ ] 🪓 나무 한 그루 → 오른쪽 **🔨 제작** → 🔨 제작대 설치 도구 → 들면 **초록 미리보기** → 공격 버튼으로 설치 (R / ⟳ = 돌리기, 빨강이면 이유가 나옴)
  - [ ] 제작대 가까이 **[F] 제작** → 🧱 벽 · 🏹 포탑 설치 도구 → 길목에 설치 → 밤에 괴물이 **그 벽을 부수며** 온다
  - [ ] 제작대 **[E] 강화** → Lv2 (돌 화덕) · Lv3 (쇠 틀 · 수정 등). 벽·포탑 Lv2 는 제작대 Lv2 가 있어야 된다
  - [ ] 놓은 구조물 **[G] 길게** → 설치 도구로 돌려받기 (다친 데 없을 때 · 낮)
  - [ ] 도끼·곡괭이는 세워서 들고 내려찍기, 창은 찌르기 (지난번 고친 것)
- **끝나고**
  - [ ] 결과 화면에 **🎁 보상 알** (3밤 이상 보통 알 · 5밤 희귀한 알) → 20초 뒤 **로비로**
  - [ ] 부화장에 알 넣기 → (보통 1분 30초 · 희귀 3분) → **깨우기** → 흔들리다 깨지는 연출 → 🐾 내 펫에서 이름 짓기
- [ ] 출력 창(보기 → 출력)에 빨간 오류가 없다 · 휴대폰(기기 에뮬레이터)에서 버튼이 겹치지 않는다
- [ ] 스크린샷 + 느낀 점(재미없는 순간, 헷갈린 순간)을 Claude 에게 보내기

**지난번(2026-09-30 오전)에 고친 것도 같이**: 도구 쥐는 법·휘두르기 · 나무/건물 충돌 · 모든 나무 베기 · 맵 경계 · 오른쪽 위 미니맵(가 본 곳만, M = 큰 지도)

오류가 뜨면 **출력 창의 빨간 줄을 그대로 복사해서** Claude 에게 보내면 된다.

크레딧이 모자라면: 다음 달까지 기다리거나, 재미가 확인된 뒤 **Pro 를 한 달만($20)** 결제해서 나머지를 몰아서 만들고 해지.

## 6. 효과음 넣기 (선택, 20분)

지금은 Roblox 내장 기본 소리(칼 휘두르는 소리 등)를 임시로 쓰고 있다. 생존 분위기에는 소리가 크게 중요하다.

1. [ ] 무료(CC0) 효과음 받기
   - Kenney **Impact Sounds**: https://kenney.nl/assets/impact-sounds
   - Kenney **Interface Sounds**: https://kenney.nl/assets/interface-sounds
2. [ ] 아래 표를 보고 칸마다 어울리는 소리를 하나씩 고른다 (직접 들어보고 고르는 게 제일 좋다)

   | AudioConfig 이름 | 언제 나오나 | 고를 소리 느낌 | 추천 팩 |
   |---|---|---|---|
   | `Attack` | 창 찌르기 · 채집 | 짧은 "퍽/툭" | Impact (punch, wood) |
   | `Arrow` | 포탑 화살 | 가벼운 "틱" | Impact (light) |
   | `Build` | 건설 · 수리 | 나무 두드리는 소리 | Impact (wood, plank) |
   | `Capture` | 포획 성공 | 밝은 "띠링" | Interface (confirmation) |
   | `Fail` | 포획 실패 | 낮은 "뚝" | Interface (error) |
   | `Secured` | 영구 확정 | 조금 긴 성공음 | Interface (confirmation) |
   | `Night` | 밤 시작 | 낮고 불길한 소리 | Impact (heavy) 또는 다른 무료 효과음 |
   | `Click` | UI 버튼 | "딸깍" | Interface (click) |

3. [ ] Studio → **창 → 애셋 관리자 → 가져오기** 로 고른 `.ogg` 파일들을 올린다 (오디오 업로드는 계정별 월 한도가 있음)
4. [ ] 올린 소리 우클릭 → **ID 복사** → Claude 에게 "Capture = 123456…" 처럼 알려주면 넣어 준다
   (직접 넣으려면 `ReplicatedStorage → Shared → Config → AudioConfig` 에 `"rbxassetid://숫자"`)

## 8. ⭐ 게시해서 로비 → 원정 텔레포트 확인 (게시 후, 15분)

로비와 원정은 **같은 Place 하나**다 (공개 서버 = 로비, 로비가 만든 예약 서버 = 원정). 텔레포트는 게시한 게임에서만 된다.

- [ ] 게임을 **비공개로 게시** (파일 → Roblox에 저장)
- [ ] 게임 설정 → 보안 → **Studio API 서비스 접근 허용** 켜기 (저장용)
- [ ] 실제 Roblox 앱에서 들어가기 → 로비 캠프가 나온다 (원정 맵은 없어야 함)
- [ ] ▶ 혼자 바로 출발 → 몇 초 로딩 뒤 원정 서버 → 펫·코인·알이 그대로
- [ ] 원정이 끝나면 로비로 돌아온다 → 알이 부화장 목록에 있다 → 나갔다 다시 들어와도 펫·알이 남아 있다
- [ ] 친구와 같은 수레에 타서 함께 출발 (같은 원정 서버로 가는지)
- [ ] 실패하면 출력 창 대신 **개발자 콘솔(F9) → 서버** 의 빨간 줄을 보내기

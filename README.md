# shorts-factory

제휴 상품 쇼츠를 코드로 찍어내는 파이프라인. 카메라도, 실물 제품도, 얼굴도 없이 만든다.

JSON 한 건 = 영상 한 편. 하루 1편 만들 걸 하루 10편 만드는 게 목적이다.

```bash
npm install
npm run fonts     # 한글 폰트 내려받기 (13MB, 최초 1회)
npm run studio    # 브라우저에서 미리보기 / 수정
npm run batch     # content/*.json 전부 렌더 → out/*.mp4
```

---

## 왜 이렇게 만들었나

쇼츠 알고리즘이 보는 신호는 사실상 두 개다. 템플릿의 모든 설계가 여기서 나왔다.

| 신호 | 뜻 | 대응 |
|---|---|---|
| **스와이프 이탈률** | 0.5~5초 안에 넘기면 저품질로 낙인 | 인트로·로고 없음. **0프레임부터 후킹 문구**가 떠 있다 |
| **시청 완료율** | 끝까지 본 비율. 높으면 노출이 크게 늘어남 | **역순 카운트다운**으로 1위를 마지막에 둔다 |

업로드 직후 500~1,000명에게 먼저 뿌리고, 거기 반응이 좋아야 확대된다. 즉 **첫 3초에서 다 결정된다.**

세부 장치:
- 후킹 첫 어절은 지연 0프레임 (`instantFirstWord`)
- 상단 진행 도트 — 몇 개 남았는지 보이면 완주 욕구가 생긴다
- 가격 카운트업 — 숫자가 굴러가는 동안 시선이 묶인다
- 후킹 화면의 1위 자리는 `?`로 가림 — 끝까지 볼 유일한 이유
- 마지막 0.5초에 후킹 화면으로 되돌림 — 루프 이음새가 안 보이면 재시청이 붙는다
- 장면 전환 0.2초 — 느린 전환은 그 구간 자체가 이탈 지점이다

## 신뢰를 못 파면 가격을 판다

제휴 클릭을 만드는 축은 두 개뿐이다.

| 축 | 무기 | 이 프로젝트에서 가능한가 |
|---|---|---|
| **신뢰** | 실사용 증명 — "내가 써봤는데" | ❌ 카메라도 제품도 없다 |
| **이득** | 가격 — "지금 이 가격은 싸다" | ✅ 데이터라서 코드로 된다 |

`Ranking` / `ProblemSolve` / `Versus`는 전부 신뢰 축이다. **그 축에서는 실사용 영상 가진 사람을 못 이긴다.** 신뢰 없는 추천은 그냥 광고고, 사람들은 광고를 안 누른다.

`Deal`만 파는 게 다르다. 상품이 아니라 **가격 낙차**를 판다. "지금 싸다"는 링크 한 번이면 검증되는 사실이라 화자가 누구인지 아무도 안 따진다. 그리고 이득 축은 속도 싸움이라 자동화가 이긴다.

**그래서 `Deal`이 메인이고 나머지 셋은 보조다.**

## 포맷 4종

| 컴포지션 | 길이 | 노리는 것 |
|---|---|---|
| `Deal` | ~15초 | **"이 가격이면 사야지"** — 신뢰가 필요 없는 유일한 포맷 |
| `Ranking` | ~21초 | "1위가 뭔데?" — 완료율이 가장 높게 나오는 구조 |
| `ProblemSolve` | ~14초 | "이거 내 얘기잖아" — 공감으로 스크롤을 멈춤 |
| `Versus` | ~14초 | "얼마 차이인데?" — 댓글이 잘 붙는다 |

같은 상품으로 돌려보고 **2주 안에 이기는 하나를 고른 뒤 나머지는 버린다.** 그게 이 저장소의 사용법이다.

### 니치는 생활 소모품이 맞다

키친타올, 물티슈, 세제, 지퍼백 같은 것. 데스크테리어보다 이쪽이 낫다.

- **설명이 필요 없다.** 키친타올이 뭔지 아무도 안 물어본다. 그래서 실사용 영상이 없어도 성립하는 유일한 카테고리다
- **단가 비교가 그 자체로 콘텐츠다.** "6,900원"은 싼지 모르겠는데 "1롤당 575원"은 마트 가격이 머리에 있어서 즉시 판단된다
- **반복 구매**된다. 한 번 산 사람이 또 산다
- 여성 유입이 강하다

`unitLabel`을 채울 수 있는 상품을 고르는 게 사실상 니치 선정 기준이다.

## 가격 이력 — 시간이 지날수록 강해지는 유일한 부분

"이거 싸요"는 누구나 한다. **"역대 최저가예요"는 가격을 계속 기록한 사람만 할 수 있다.** 실사용 영상을 가진 사람도 이건 못 한다. 물건을 써봤다고 지난 6개월 가격을 아는 건 아니니까.

```bash
npm run price add 데스크패드-대형 9900     # 기록
npm run price check 데스크패드-대형 9900   # 역대 최저인지
npm run price list 데스크패드-대형         # 이력 보기
```

`Deal` JSON의 상품에 `id`를 넣어두면 **렌더할 때 가격이 자동으로 기록되고, 역대 최저면 배지가 붙는다.** 영상을 만들수록 데이터가 쌓이는 구조라 따로 관리할 게 없다.

기록이 **3건 미만이면 최저가라고 말하지 않는다.** 어제 한 번 본 게 전부인데 "역대 최저"라고 하는 건 거짓말이고, 그 한 번이 채널을 끝낸다.

이력은 `data/price-history.jsonl`에 쌓인다. **이 파일이 이 저장소에서 제일 값나가는 자산이니 반드시 커밋한다.**

### 안 적은 값은 자동으로 null이 된다 (중요)

Remotion은 컴포지션의 `defaultProps`와 넘긴 props를 **병합**한다. 그래서 JSON에 빠뜨린 필드는 조용히 다른 상품의 기본값으로 채워진다. 실제로 마감을 안 적은 키친타올 영상에 다른 상품의 "⏰ 오늘 자정까지"가 떠서, **없는 마감을 지어내는 허위 표시**가 될 뻔했다.

`render-batch.mjs`가 `Deal`의 선택 필드를 전부 `null`로 못 박아 기본값을 덮는다. 필드를 새로 추가하면 `NULLABLE_DEAL_FIELDS` / `NULLABLE_ITEM_FIELDS`에도 같이 넣어라. 안 그러면 같은 사고가 난다.

`npm run studio`로 미리보기할 때는 이 방어가 안 걸린다(기본값이 그대로 보인다). **최종 확인은 반드시 `npm run batch`로 뽑은 mp4로 한다.**

### 특가는 몇 시간이면 끝난다

`Deal`의 `priceCheckedAt`은 필수 필드다. 올린 뒤 가격이 올라가 있으면 신뢰가 한 번에 무너지고 허위 표시 문제도 생긴다. 시점을 화면에 박아두는 게 유일한 방어다. 지우지 마라.

다만 **문구가 변명이면 안 된다.** 처음엔 "지금은 다를 수 있어요"라고 썼는데, 그건 살 마음을 직접 꺾는 문장이었다. `7/26 오후 8시 확인`이면 방어는 똑같이 되면서 정보처럼 읽힌다. 마무리도 "품절되면 죄송해요"에서 `놓치면 다시 23,900원`으로 바꿨다 — 마지막 화면에서 사과하면 여태 쌓은 게 무너진다.

### 지어내도 되는 값은 하나도 없다

`deadline`, `stockWarning`, `badges`, `rating`, `reviewCount`는 **판매 페이지에 실제로 그렇게 적혀 있을 때만** 넣는다. 없는 마감이나 "품절임박"을 붙이면 클릭이 몇 번 더 나오겠지만, 링크 눌러보면 바로 들통난다. 그게 마지막 클릭이 된다. 허위 표시는 파트너스 약관 위반이기도 하다.

## 화면 톤 — 밝은 쪽이 기본이다

`theme`으로 `"light"`(기본) / `"dark"`를 고른다.

처음엔 어두운 네온으로 만들었는데, 한국에서 **검은 배경 + 형광 민트·핑크는 도박·코인 광고의 시각 언어**다. 피드에서 "광고"로 먼저 읽힌다. 반면 토스·쿠팡·네이버쇼핑은 전부 흰 배경에 검정 글씨고, 밝으면 "정보"로 읽힌다. 실사용 영상이 없어 이미 신뢰가 부족한 판이라 이 차이가 크다.

다만 어느 쪽이 실제로 이길지는 추측이므로 둘 다 남겨뒀다. 같은 상품으로 두 벌 뽑아 올려보고 데이터로 결정한다.

## 나레이션 대본

`narration` 배열에 적어둔다. 화면에는 안 나오고, TTS는 직접 입힌다.

대본을 따로 관리하면 상품 정보를 고치고 대본 고치는 걸 잊어서 **가격이 안 맞는 사고**가 난다. 같은 파일에 둔다.

쓰는 규칙:
- **숫자는 한글로.** "23,900원"을 TTS에 그대로 넣으면 엔진마다 다르게 읽는다. "이만 삼천구백원"으로 적는다
- **1초에 5~6음절.** 15초 영상이면 전체 75~90음절이 한계다. 넘치면 말이 빨라져서 싸구려로 들린다
- **화면에 있는 말을 반복하지 않는다.** 자막을 그대로 읽으면 지루하다. 화면은 숫자, 목소리는 맥락
- **첫 문장은 후킹과 같은 말로.** 소리를 끄고 보는 사람이 절반이라 화면만으로도 성립해야 한다

## 영상 하나 만들기

`content/` 에 JSON을 넣고 `npm run batch`.

```json
{
  "template": "Ranking",
  "slug": "desk-top5",
  "hook": "책상 이거 하나 놨더니 방 분위기 바뀜",
  "subHook": "전부 3만원 아래",
  "cta": "링크는 댓글에 있어요",
  "items": [
    { "name": "무선 무드등", "punch": "불 끄고 이거만 켜면 방이 카페가 됨", "price": 18900, "emoji": "💡" }
  ]
}
```

- `items`는 **1위부터** 넣는다. 화면에는 알아서 꼴찌부터 나온다.
- 이미 만든 영상은 건너뛴다. 다시 만들려면 `npm run batch -- --force`.
- 상품 개수에 따라 영상 길이가 자동으로 맞춰진다.

### 후킹 쓰는 규칙

조회수의 90%가 여기서 갈린다. 나머지는 자동화가 해준다.

- **12자 안쪽.** 길면 3초 안에 못 읽는다
- **결과부터.** "무드등 추천" ❌ → "책상 이거 하나 놨더니 방 분위기 바뀜" ⭕
- **스펙 금지.** "5600K 밝기조절" ❌ → "불 끄고 이거만 켜면 카페 됨" ⭕
- LLM한테 5개 뽑게 하고 **고르는 건 직접 한다.** 여기만 사람이 하면 된다

## 상품 이미지에 대해

지금은 `emoji` + 그라데이션 카드로 그린다. 쓸 수 있는 상품 이미지가 없어서다.

- 쿠팡 오픈API는 **누적 판매 15만원**을 넘겨야 열린다 (팔아야 API를 준다)
- 토스 쉐어링크는 크리에이터용 API가 **아예 없다**. 판매자용 API만 있음
- 상세페이지 이미지 크롤링은 판매자 저작물이라 **쓰면 안 된다**

그래서 순서가 이렇게 된다.

1. **손으로 상품 고르고 링크 뽑아서** JSON에 채운다 → 그래픽만으로 영상 생산
2. 누적 15만원(고객 결제액 기준, 3만원짜리 5개면 넘는다)을 뚫으면 API가 열린다
3. 그때 `Product.image`에 URL만 채우면 된다. **컴포넌트는 안 바꿔도 된다**

## 표기 의무

`Disclosure` 컴포넌트는 빼지 마라. 공정위 추천·보증 심사지침상 제휴 수수료를 받는 콘텐츠는 그 사실을 표시해야 하고, 쿠팡파트너스 약관에도 같은 의무가 있다. 누락은 활동 정지 사유다.

영상 설명란에도 같은 문구를 넣는다.

## 4주 계획과 손절 기준

| 주차 | 할 것 | 보는 숫자 |
|---|---|---|
| 1주 | 니치 확정 + 파이프라인 손에 익히기 | 영상 1편이 10분 안에 나오는가 |
| 2주 | 하루 3편 × 7일, 포맷 3종 A/B | 조회수 1,000 넘는 게 하나라도 있는가 |
| 3주 | 이긴 포맷만 남기고 나머지 폐기 | 조회수 대비 링크 클릭률 |
| 4주 | 이긴 포맷으로 하루 5~10편 | 누적 판매 15만원 돌파 여부 |

**4주 뒤 조회수 1,000 넘는 영상이 0개면 접는다.** 될 건 초반에 신호가 온다. 손절 기준을 미리 정해두는 게 6개월 태우고 후회하는 것보다 낫다.

## 구조

```
content/            렌더할 일감 (JSON 하나 = 영상 하나)
data/               가격 이력 (커밋할 것 — 유일하게 쌓이는 자산)
src/
  templates/        포맷 4종
  components/       후킹 글자, 순위 배지, 가격표, 진행 도트 …
  theme.ts          색·타이포·쇼츠 UI 안전영역
  types.ts          Product 스키마 (나중에 API 응답이 이 모양으로 들어온다)
scripts/
  fetch-fonts.mjs    한글 폰트 내려받기
  render-batch.mjs   배치 렌더
  price-history.mjs  가격 기록 / 역대 최저가 판정
```

### 안전영역

유튜브·릴스는 하단(제목·채널명)과 우측(좋아요·댓글)에 자기 UI를 덮는다. 거기 글자를 두면 가려진다. `theme.ts`의 `SAFE`가 그 여백이니 함부로 줄이지 마라.

### 알아둘 것

- **TypeScript는 5.x여야 한다.** 7.x는 Remotion 번들러와 API가 안 맞아서 빌드가 죽는다
- 한글 TTF가 6MB씩이라 렌더 탭을 여러 개 띄우면 기본 타임아웃(30초)을 넘긴다. `remotion.config.ts`에서 타임아웃과 동시성을 조정해 뒀다
- 색에 투명도를 줄 때는 `alpha()`를 쓴다. `${color}CC` 같은 문자열 이어붙이기는 `interpolateColors`가 돌려주는 `rgba()` 값과 만나면 CSS가 통째로 무시된다

# shorts-factory

제휴 상품 쇼츠를 코드로 찍어내는 파이프라인. 카메라도, 실물 제품도, 얼굴도 없이 만든다.

JSON 한 건 = 영상 한 편. 하루 1편 만들 걸 하루 10편 만드는 게 목적이다.

```bash
npm install
npm run fonts     # 한글 폰트 내려받기 (13MB, 최초 1회)
npm run studio    # 브라우저에서 미리보기 / 수정
npm run batch     # content/*.json 전부 렌더 → out/*.mp4
```

---

## 왜 이렇게 만들었나

쇼츠 알고리즘이 보는 신호는 사실상 두 개다. 템플릿의 모든 설계가 여기서 나왔다.

| 신호 | 뜻 | 대응 |
|---|---|---|
| **스와이프 이탈률** | 0.5~5초 안에 넘기면 저품질로 낙인 | 인트로·로고 없음. **0프레임부터 후킹 문구**가 떠 있다 |
| **시청 완료율** | 끝까지 본 비율. 높으면 노출이 크게 늘어남 | **역순 카운트다운**으로 1위를 마지막에 둔다 |

업로드 직후 500~1,000명에게 먼저 뿌리고, 거기 반응이 좋아야 확대된다. 즉 **첫 3초에서 다 결정된다.**

세부 장치:
- 후킹 첫 어절은 지연 0프레임 (`instantFirstWord`)
- 상단 진행 도트 — 몇 개 남았는지 보이면 완주 욕구가 생긴다
- 가격 카운트업 — 숫자가 굴러가는 동안 시선이 묶인다
- 후킹 화면의 1위 자리는 `?`로 가림 — 끝까지 볼 유일한 이유
- 마지막 0.5초에 후킹 화면으로 되돌림 — 루프 이음새가 안 보이면 재시청이 붙는다
- 장면 전환 0.2초 — 느린 전환은 그 구간 자체가 이탈 지점이다

## 포맷 3종

| 컴포지션 | 길이 | 노리는 것 |
|---|---|---|
| `Ranking` | ~21초 | "1위가 뭔데?" — 완료율이 가장 높게 나오는 구조 |
| `ProblemSolve` | ~14초 | "이거 내 얘기잖아" — 공감으로 스크롤을 멈춤 |
| `Versus` | ~14초 | "얼마 차이인데?" — 댓글이 잘 붙는다 |

셋을 같은 상품으로 돌려보고 **2주 안에 이기는 하나를 고른 뒤 나머지는 버린다.** 그게 이 저장소의 사용법이다.

## 영상 하나 만들기

`content/` 에 JSON을 넣고 `npm run batch`.

```json
{
  "template": "Ranking",
  "slug": "desk-top5",
  "hook": "책상 이거 하나 놨더니 방 분위기 바뀜",
  "subHook": "전부 3만원 아래",
  "cta": "링크는 댓글에 있어요",
  "items": [
    { "name": "무선 무드등", "punch": "불 끄고 이거만 켜면 방이 카페가 됨", "price": 18900, "emoji": "💡" }
  ]
}
```

- `items`는 **1위부터** 넣는다. 화면에는 알아서 꼴찌부터 나온다.
- 이미 만든 영상은 건너뛴다. 다시 만들려면 `npm run batch -- --force`.
- 상품 개수에 따라 영상 길이가 자동으로 맞춰진다.

### 후킹 쓰는 규칙

조회수의 90%가 여기서 갈린다. 나머지는 자동화가 해준다.

- **12자 안쪽.** 길면 3초 안에 못 읽는다
- **결과부터.** "무드등 추천" ❌ → "책상 이거 하나 놨더니 방 분위기 바뀜" ⭕
- **스펙 금지.** "5600K 밝기조절" ❌ → "불 끄고 이거만 켜면 카페 됨" ⭕
- LLM한테 5개 뽑게 하고 **고르는 건 직접 한다.** 여기만 사람이 하면 된다

## 상품 이미지에 대해

지금은 `emoji` + 그라데이션 카드로 그린다. 쓸 수 있는 상품 이미지가 없어서다.

- 쿠팡 오픈API는 **누적 판매 15만원**을 넘겨야 열린다 (팔아야 API를 준다)
- 토스 쉐어링크는 크리에이터용 API가 **아예 없다**. 판매자용 API만 있음
- 상세페이지 이미지 크롤링은 판매자 저작물이라 **쓰면 안 된다**

그래서 순서가 이렇게 된다.

1. **손으로 상품 고르고 링크 뽑아서** JSON에 채운다 → 그래픽만으로 영상 생산
2. 누적 15만원(고객 결제액 기준, 3만원짜리 5개면 넘는다)을 뚫으면 API가 열린다
3. 그때 `Product.image`에 URL만 채우면 된다. **컴포넌트는 안 바꿔도 된다**

## 표기 의무

`Disclosure` 컴포넌트는 빼지 마라. 공정위 추천·보증 심사지침상 제휴 수수료를 받는 콘텐츠는 그 사실을 표시해야 하고, 쿠팡파트너스 약관에도 같은 의무가 있다. 누락은 활동 정지 사유다.

영상 설명란에도 같은 문구를 넣는다.

## 4주 계획과 손절 기준

| 주차 | 할 것 | 보는 숫자 |
|---|---|---|
| 1주 | 니치 확정 + 파이프라인 손에 익히기 | 영상 1편이 10분 안에 나오는가 |
| 2주 | 하루 3편 × 7일, 포맷 3종 A/B | 조회수 1,000 넘는 게 하나라도 있는가 |
| 3주 | 이긴 포맷만 남기고 나머지 폐기 | 조회수 대비 링크 클릭률 |
| 4주 | 이긴 포맷으로 하루 5~10편 | 누적 판매 15만원 돌파 여부 |

**4주 뒤 조회수 1,000 넘는 영상이 0개면 접는다.** 될 건 초반에 신호가 온다. 손절 기준을 미리 정해두는 게 6개월 태우고 후회하는 것보다 낫다.

## 구조

```
content/            렌더할 일감 (JSON 하나 = 영상 하나)
src/
  templates/        포맷 3종
  components/       후킹 글자, 순위 배지, 가격표, 진행 도트 …
  theme.ts          색·타이포·쇼츠 UI 안전영역
  types.ts          Product 스키마 (나중에 API 응답이 이 모양으로 들어온다)
scripts/
  fetch-fonts.mjs   한글 폰트 내려받기
  render-batch.mjs  배치 렌더
```

### 안전영역

유튜브·릴스는 하단(제목·채널명)과 우측(좋아요·댓글)에 자기 UI를 덮는다. 거기 글자를 두면 가려진다. `theme.ts`의 `SAFE`가 그 여백이니 함부로 줄이지 마라.

### 알아둘 것

- **TypeScript는 5.x여야 한다.** 7.x는 Remotion 번들러와 API가 안 맞아서 빌드가 죽는다
- 한글 TTF가 6MB씩이라 렌더 탭을 여러 개 띄우면 기본 타임아웃(30초)을 넘긴다. `remotion.config.ts`에서 타임아웃과 동시성을 조정해 뒀다
- 색에 투명도를 줄 때는 `alpha()`를 쓴다. `${color}CC` 같은 문자열 이어붙이기는 `interpolateColors`가 돌려주는 `rgba()` 값과 만나면 CSS가 통째로 무시된다

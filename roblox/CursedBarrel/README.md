## 38.5 · 튜토리얼이 지루해서 중간에 나가는 문제

실수 없이 끝까지 해도 튜토리얼이 약 1분 50초였고, 그중 내가 실제로 누르는 시간은 몇 초뿐이었습니다.

| 기다리는 것 (실수 없이 한 번) | 예전 | 지금 |
|---|---|---|
| 환영 창 자동 시작 | 30초 | 15초 (38.4) |
| 판 시작 카운트다운 | 5초 | 2초 |
| 첫 차례 전 AI 차례 | 평균 약 7초 (차례 순서가 무작위) | 없음 (내가 항상 먼저) |
| 내 차례 사이 AI 차례 | 약 14초 (AI 둘 · "한 번 더" 포함) | 약 3초 (AI 하나) |
| 해적이 나오기 전 설명 카드 | 3.5초 × 3 | 2.6초 × 3 |
| 한 종류 잡은 뒤 쉬는 시간 | 3.8초 × 3 | 2.4초 × 3 |
| 쌍둥이 첫째 잡고 둘째까지 | 2.5초 이상 (그 사이 누르면 "너무 빨랐다") | 약 1.3초 |
| 놓쳐서 다시 할 때 | 1.7초 + 설명 카드 다시 3.5초 | 1.7초 + 1.6초 (카드 없이) |
| **합계 (앉은 뒤)** | **약 80초** | **약 40초** |

숫자는 모두 `GameConfig.Tutorial` 에 있습니다 (`IntroLead` · `IntroShow` · `RetryLead` · `TwinFirstWindow` · `TwinGap` · `Countdown` · `SafeHold` · `StepPause` · `BotThinkExtra` · `Bots`).

### 어디서 나가는지 기록 (새로 추가)

튜토리얼을 마치기 전에 나가면 분석 이벤트 **`TutorialQuit`** 를 남깁니다.

- 값 : 들어온 뒤 몇 초 만에 나갔나
- 필드 1 : `welcome`(환영 창) · `finding`(테이블 찾는 중) · `starting`(판 시작 대기) · `playing`(판 진행 중)
- 필드 2 : 몇 단계였나 (1 보통 · 2 쌍둥이 · 3 해골)
- 필드 3 : 해적 종류 (`normal` · `twin` · `skull`)

Creator Dashboard 의 게임 분석(Analytics)에 있는 맞춤 이벤트(Custom Events)에서 볼 수 있습니다.
원래 있던 온보딩 퍼널(1 Joined → 2 TutorialStarted → 3 FirstPirate → 4 TutorialDone)과 같이 보면 어느 구간에서 빠지는지 알 수 있습니다.

## 38.4 · 튜토리얼이 처음부터 다시 시작되던 버그

1. 스페이스 / 점프 버튼을 누르면 의자에서 일어나 튜토리얼 판이 기권 처리 → 다시 앉혀져 1단계부터.
   → 튜토리얼 중에는 일어나지 않게 붙잡음 (마치거나 건너뛰면 풀림)
2. 칼 버튼을 안 누르면(서버가 대신 고름) 세 번째에 자리 비움으로 쫓겨남 → 해골 유령 직전에 1단계부터.
   → 튜토리얼 중에는 자리 비움으로 쫓아내지 않음
3. 판에서 빠지면 진행이 사라짐 → 잡은 단계부터 이어서
4. 튜토리얼 판 AI 가 테이블을 꽉 채움(4인 = 셋 · 6인 = 다섯) + AI 가 "한 번 더" → AI 하나, "한 번 더" 없음
5. 빈 3인 이상 테이블만 쓸 수 있어 붐비는 서버에서 최대 45초 대기 → 2인 테이블도 사용, 25초

## Studio 에서 확인해 볼 것

- 새 계정(또는 DataStore 초기화)으로 튜토리얼을 끝까지 → 시간이 1분 안팎인지, 내가 먼저 시작하는지
- 쌍둥이 : 첫째를 잡고 둘째가 금방 나오는지
- 일부러 실패 → 설명 카드 없이 금방 다시 나오는지
- 해적이 나오기 전 · 잡은 뒤에 스페이스 연타 → 자리에서 안 일어나는지
- Studio 출력 창에 튜토리얼 도중 나가면 `튜토리얼 도중 나감 (...)` 로그가 찍히는지 (로그가 켜져 있을 때)

# CursedBarrel · Phase 38.4 튜토리얼 이탈 수정

원본: `CursedBarrel_Phase38_3_fixed.rbxl` → 수정본: `CursedBarrel_Phase38_4_tutorialfix.rbxl`
스크립트 5개만 바뀌었고 나머지(맵 · 모델 · 다른 스크립트 66개)는 그대로입니다. 바뀐 줄은 `tutorial-fix.patch` 에 있습니다.

## 왜 튜토리얼에서 나갔나 (코드에서 확인한 원인)

1. **스페이스 / 점프 버튼 = 튜토리얼 강제 종료 후 처음부터 다시**
   환영 창이 PC 에서 "클릭(스페이스)해서 잡아요"라고 가르치는데, 스페이스는 해적을 잡는 그 순간에만 막혀 있었습니다.
   해적이 나오기 전 · 잡은 뒤 · AI 차례에 스페이스(휴대폰은 점프 버튼)를 누르면 의자에서 일어나 튜토리얼 판이 기권으로 끝나고,
   3초 뒤 다시 앉혀져 **보통 해적부터 다시** 했습니다.
2. **칼 버튼을 안 누르면 마지막 단계 직전에 쫓겨남**
   7초 안에 칼 자리를 못 고르면 서버가 대신 골라 주는데, 이게 세 번이면 "자리 비움"으로 자리에서 일으켜 세웠습니다.
   튜토리얼은 정확히 차례 세 번(보통 · 쌍둥이 · 해골)이 필요해서, 해적은 잘 잡아도 **해골 유령 직전에 쫓겨나 처음부터** 다시 했습니다.
   해적을 잡아도 자리 비움 횟수는 초기화되지 않았습니다.
3. **떨어지면 진행이 사라짐** — 위 1 · 2 처럼 판에서 빠지면 무조건 1단계부터.
4. **AI 차례 구경 시간이 너무 김** — Phase 24 에서 AI 가 테이블을 꽉 채우게 바뀌면서 튜토리얼도
   4인 테이블은 AI 셋, 6인 테이블은 AI 다섯이 앉았습니다 (처음 설계는 "AI 둘"). AI 는 튜토리얼에서도 "한 번 더"까지 해서
   내 차례 사이마다 15~30초씩 가만히 구경만 했습니다.
5. **대기 시간** — 환영 창 30초 자동 시작, 붐비는 서버에서는 빈 3인 이상 테이블을 못 찾아 "튜토리얼 테이블로 안내하는 중…"만
   최대 45초 (그동안 다른 테이블에도 못 앉음).

## 고친 것

| 파일 | 내용 |
|---|---|
| TutorialController | 튜토리얼 판에 앉아 있는 동안 스페이스 · 점프로 일어나지 않게 붙잡음. 튜토리얼을 마치거나 건너뛰면 풀림 |
| Phase4Controller | 잡기가 끝날 때 의자 잠금이 점프를 다시 켜지 않게 (튜토리얼 중일 때만) |
| RoundService | 튜토리얼 중에는 자리 비움으로 쫓아내지 않음 (정말 자리 비운 사람은 기존 MaxIdleMisses 가 끝냄) |
| RoundService | 잡은 단계를 기억해 다시 앉혀지면 그 단계부터 이어서 (이번 접속 동안) |
| RoundService | 튜토리얼 판에서는 AI 도 "한 번 더" 안 함 |
| BotService | 튜토리얼 판 AI 는 `Tutorial.Bots`(1) 명만. 빈 의자 2개면 튜토리얼 가능 → 스폰 앞 2인 테이블도 사용 |
| GameConfig | `Tutorial.Bots = 1`, `WelcomeWait` 30 → 15, `GiveUpAfter` 45 → 25 |

AI 수나 대기 시간은 `GameConfig.Tutorial` 에서 숫자만 바꾸면 됩니다.

## Studio 에서 확인해 볼 것

- 새 계정(또는 DataStore 초기화)으로 들어가 튜토리얼 판에서 해적이 나오기 전 · 잡은 뒤에 스페이스를 연타 → 자리에서 안 일어나야 함
- 칼 버튼을 전혀 누르지 않고 기다림 → 서버가 대신 골라 주고, 세 단계 모두 쫓겨나지 않고 끝나야 함
- 튜토리얼 테이블에 AI 가 한 명만 앉는지, 튜토리얼이 끝나면 스페이스로 다시 일어설 수 있는지
- 해적 하나 잡은 뒤 「튜토리얼 건너뛰기」 두 번 → 자리에서 일어나고 다른 테이블에 앉을 수 있는지

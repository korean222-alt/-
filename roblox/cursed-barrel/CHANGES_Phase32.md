## 같은 패턴이라 질리던 문제

### 해적 종류 (`GameConfig.PirateKinds`)

| 종류 | 잡는 법 | 몇 라운드부터 |
|---|---|---|
| ☠ 해적 | 튀어나오면 한 번 | 1 |
| 👯 쌍둥이 해적 | 두 마리가 차례로. 나올 때마다 한 번씩 (둘째 전에 누르면 너무 빨랐다) | 2 |
| 🪝 갈고리 해적 | 튀어나온 쪽(왼쪽 · 오른쪽)을 누른다 | 3 |
| 👻 해골 유령 | 누르면 탈락! 사라질 때까지 참는다 | 4 |
| 💰 욕심쟁이 해적 | 시간 안에 5번(라운드가 오르면 최대 8번) 연타 | 5 |
| 😡 분노한 해적 | 먹물을 뚫고 튀어나올 때 | 7 |

- 판정은 전부 서버가 한다. AI 선원도 같은 방법으로 누른다.
- **스킨과 함께 쓰는 법** : 해적 스킨(부품 해적 · Blender 해적 · 용 세트 …)은 그대로 두고 그 위에 종류 색 테두리(Highlight) · 머리 위 표시 · 화면 안내만 덧입힌다. 쌍둥이는 같은 스킨 둘이 나란히, 해골 유령은 같은 스킨이 반투명으로 나온다. 그래서 어떤 스킨이든 종류가 똑같이 알아보인다.
- 해적이 나오기 전 통 틈에서 **종류 색의 빛**이 새어 나온다 (잘 보면 미리 안다).
- 처음 만나는 종류는 해적이 적어도 2초 뒤에 나오고 **설명 카드**가 1.5초 뜬다 (한 사람에게 한 번 · Phase 35).

### 운명 카드 (`GameConfig.FateCards`)

라운드(통)가 새로 시작될 때마다 한 장을 뒤집어 보여 주고(2.6초 동안 차례를 멈춘다), 그 라운드만 규칙이 바뀐다.
알림판 아래에 한 줄로 남는다. 1라운드는 순한 카드만.

황금 통 · 졸린 해적 · 성난 바다 · 쌍둥이의 밤 · 유령선 · 갈고리 폭풍 · 황금 욕심 · 행운의 통 · 불꽃 칼날 · 배짱 축제 · 떠도는 해적 · 급한 물살 · 잔잔한 바다 (13장, 확률 · 효과는 표에서 바꾼다)

### 8라운드 벽을 없앴다 (끝없는 라운드)

코드에 라운드 상한은 없었다. **16번 잡은 뒤로는 창 0.16~0.24초짜리 분노한 해적만 나와서** 사실상 8라운드쯤이 끝이었다.

- `MaxPerPlayer` 16 → 9999 (그 벽을 없앰). 분노한 해적은 7라운드부터 가끔 섞이는 종류가 됐다.
- 창의 바닥 0.20 → **0.30초**, 0.40초부터는 한 번에 0.01초씩만 좁아진다.
- 5라운드마다 살아 있는 사람에게 150 코인 (`GameConfig.Endless`).
- 모의 실험에서 한 번도 안 놓치는 두 사람은 30라운드를 넘긴다 (실제 사람은 종류 · 카드 때문에 언젠가 놓친다).

## Phase 32.1 : 타로 카드 그림 · 이모지 없애기 · 튜토리얼 천천히

### 운명 카드 · 아이콘 그림 (Blender)

- `art/render_art.py` (Blender 4.2 · Cycles) 로 타로 카드 13장 + 뒷면, 해적 종류 아이콘 8개(해적 · 쌍둥이 · 갈고리 · 유령 · 욕심쟁이 · 분노 · 구명환 · 자물쇠)를 렌더했다.
  `art/pack_sheets.py` 가 Roblox 이미지 한 장 한도(1024px)에 맞춰 네 장으로 묶는다 → `art/sheets/`.
- **올리는 법** : Studio → 보기 → 에셋 관리자 → 이미지 가져오기로 `art/sheets/` 의 PNG 네 장을 올리고, 각 이미지를 오른쪽 클릭 → 에셋 ID 복사 →
  `ReleaseConfig.Images.FateCards = { cards_1, cards_2, cards_3 }` · `ReleaseConfig.Images.PirateIcons = icons` 에 숫자를 적는다.
  올리기 전(0)에는 같은 모양(남색 카드 · 금테 · 로마 숫자 · 둥근 창 · 휘장)을 UI 로 그려 보여 준다 (`Shared/ArtAtlas`).
- 운명 카드는 뒷면(보라 나침반) → 뒤집혀 앞면. 이름은 그림의 이름판 위에, 규칙은 카드 아래 띠에. 읽을 시간을 늘렸다 (`RevealTime` 2.6 → 3.4초).
- **그 테이블에 앉은 사람과 관전하는 사람 모두에게 같은 카드가 보인다** (다른 테이블 사람에게는 안 보인다).

### 이모지 없애기

- Phase 32 에서 더한 화면 글 · 버튼 · 알림의 이모지를 모두 뺐다. 해적 머리 위 표시 · 설명 카드 · 튜토리얼 체크 목록 · 룰렛 자물쇠 · 신입 보호는 아이콘 그림을 쓴다.
- `GameConfig.PirateKinds` · `FateCards` 의 `icon` 칸을 없앴다 (그림은 ArtAtlas 가 id 로 찾는다).
- Phase 31 까지 있던 이모지(알림판의 인원 · 현상금 표시, 날씨, 방해 아이템 등)는 그대로 두었다.

### 화면 정리

- 해적 설명 카드 540x180 → **460x150**, 화면 가운데(잡기 고리 위)에서 **알림판 바로 아래**로 옮겼다.
- 잡기 안내는 **한 줄만**. 예전에는 종류 안내 · 신입 보호 · "먼저 누르면 탈락" 세 줄이 겹쳐 떴다. 신입 보호는 작은 구명환 표시로.
- 튜토리얼의 "칼 꽂을 자리를 골라요" 문구는 **첫 차례에 한 번만** (5초) 뜬다.

## Phase 38 : 종류마다 세지는 능력 · 칼 던지기 · 1인칭 고개 · 룰렛 3판

### 빨라지는 것은 보통 해적뿐, 나머지는 능력이 세진다 (`RoundService._startCatch` · `GameConfig.PirateKinds`)

보통 해적만 잡을수록 창이 좁아지고 빨리 나온다. 나머지 종류는 창 · 나오는 박자가 처음 그대로(운명 카드 배율만)이고,
라운드가 오를수록(kindLevel = 라운드 − 그 종류가 풀린 라운드) 그 종류만의 능력이 세진다.

| 종류 | 풀리는 라운드 | 세지는 것 |
|---|---|---|
| 쌍둥이 | 2 | 둘째가 나오는 간격이 들쭉날쭉 (0.45~0.85초 → 최대 0.25~1.6초). **6라운드부터 가끔 세쌍둥이** (35% → 60%) |
| 갈고리 | 3 | **5라운드부터 속임수** : 진짜가 나오기 직전 반대쪽으로 고개를 내밀었다 들어간다 (30% → 70%) · 그때 누르면 너무 빨랐다 |
| 해골 유령 | 4 | 라운드마다 0.1초 더 오래 떠 있다 (1.2 → 2.2초). **6라운드부터 사라지는 척 깜빡인다** (그때 눌러도 탈락) |
| 욕심쟁이 | 5 | 2라운드마다 연타 +1번 (5 → 최대 12번). 시간은 줄지 않고 (횟수/5)^0.7 배로 조금 는다 |
| 분노한 해적 | 7 | 그대로 (먹물 · 좁은 창) |

위의 작은 띠가 세진 능력을 알려 준다 : "세쌍둥이 해적 · 셋 다 잡기!" · "연타 9번!" · "속임수 조심!" · "깜빡여도 참아!".
튜토리얼에서는 세지지 않는다. 모의 실험(잘하는 두 사람 30라운드)에서 보통 해적 창 0.26초까지 · 다른 종류 창은 줄지 않음 · 세쌍둥이 · 속임수 · 깜빡임 · 연타 12번이 모두 나오는 것을 검사한다.

### 칼 던지기

잡는 방법(타이밍 · 방향 · 연타 · 참기)은 그대로이고, **누를 때마다 칼을 던진다**. 맞는 때면 해적에 꽂혀 함께 통 속으로 끌려 들어가고,
너무 빠르거나 반대쪽이거나 유령이면 빗나간다. 1인칭이면 1인칭 손이 휙 던지고 새 칼을 뽑아 든다. 3인칭이면 내 캐릭터 손에서 날아간다.
다른 사람이 잡으면 그 사람 손에서 해적마다 한 자루씩 날아간다. 칼은 각자 장착한 칼 스킨.

### 1인칭 고개

화면 끌기(휴대폰 · 마우스) · ← → A D(좌우) · ↑ ↓ W S(위아래) · 게임패드 오른쪽 스틱으로 고개를 돌린다. 좌우는 끝없이, 위아래는 −63° ~ +57°.
해적이 튀어나오면 잠깐 해적을 보고, 끝나면 돌려 둔 곳으로 돌아온다. 새 판이 시작되면 정면. (잡는 중에는 화면 누름이 잡기라 돌지 않는다)

### 룰렛

오늘 **3판**(AI 판 포함)을 끝까지 하면 열린다 (`GameConfig.Roulette.GamesToUnlock = 3`). 버전 `38.0.0`.

## Phase 38.1 : 던질 준비 자세

해적을 기다리는 동안(내 잡기 · 해적이 나오기 전 · 쌍둥이 다음 마리 · 연타 중) 칼을 뒤로 젖혀 던질 준비를 한다.
- 1인칭 : 1인칭 손이 칼을 어깨 뒤로 젖힌다. 해적이 나올 때가 가까울수록(1.5초 전부터) 더 젖히고 손이 떨린다. 누르면 그 자세에서 휙 던진다.
- 3인칭 : 내 캐릭터가 오른팔을 머리 뒤로 젖히고 몸을 살짝 비튼다. 손에 칼을 쥐고 있다. 누르면 팔을 휘둘러 던지고, 쌍둥이 · 연타가 남았으면 다시 젖힌다 (`StabMotion.throwReady` · `throwSwing`).
- 해골 유령일 때도 똑같이 칼을 든다 (자세만 보고 유령인지 알 수 없게 · 참는 것은 사람 몫).
- 관절 자세는 내 화면에서만 바뀐다 (다른 사람 화면에는 던지는 칼만 보인다). 버전 `38.1.0`.

## Phase 38.2 : 관전 중 "탈락"이 먼저 뜨던 버그 · 갈고리 해적 쉽게

- **버그** : 관전할 때 해적(특히 오래 떠 있는 해골 유령)이 나오면 "○○ · 탈락"이 먼저 뜨고, 잡으면 "잡았다"가 떴다.
  - 원인 1 : 관전 테이블(SpectateTableId)을 화면(클라이언트)에서만 달았다. 클라이언트가 Player 에 단 Attribute 는 서버로 가지 않아서
    서버는 관전자를 몰랐고, 관전자에게 해적 잡기 정보(CatchPrompt)를 보내지 않았다.
  - 원인 2 : 잡기 정보를 0.25초 안에 못 받으면 "잡기가 꺼진 서버"로 여기고 탈락 연출(달려드는 해적 + "○○ · 탈락")을 보여 주는 옛 대비책이 있었다.
    느린 휴대폰에서는 게임 중에도 뜰 수 있었다.
  - 고침 : 관전을 시작 · 끝낼 때 서버에 알린다 (`VoyageRequest("spectate")` · 요청 제한과 따로). 옛 대비책은 잡기가 꺼진 서버에서만 쓴다.
- **갈고리 해적** : 나오는 비율 16 → 9 (7라운드 이후 약 14% → 8%) · 잡는 시간 1.2 → 1.7배 (0.74 → 1.05초) ·
  속임수는 7라운드부터 20% → 최대 50% (예전 5라운드부터 30% → 70%). 버전 `38.2.0`.

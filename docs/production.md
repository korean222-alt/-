# 촬영·나레이션 방식

## 결론: 하이브리드

**앞 3초만 토스 화면 녹화, 나머지는 지금 그래픽.**

| 방식 | 장점 | 단점 | 판정 |
|---|---|---|---|
| 전부 화면 녹화 | 가격이 진짜라는 증거. 실물 사진 나옴 | 편당 5~10분. 자동화 불가. 세로 크롭 지저분 | ❌ 하루 10편 못 감 |
| 전부 그래픽 (지금) | 편당 1분. 가독성 최고 | "네가 만든 숫자 아니냐" | △ |
| **앞 3초 녹화 + 그래픽** | 증거 + 속도 둘 다 | 편당 2~3분 | ⭕ |

이유: 이 채널의 유일한 약점이 "저 가격 진짜야?"인데, 토스 앱에서 가격·`최저가보상` 배지가
보이는 3초가 그걸 통째로 해결한다. 그런데 15초 내내 녹화하면 자동화가 죽는다.
**증거는 3초면 충분하고 정보 전달은 그래픽이 압도적으로 낫다.**

### 녹화 규칙

- **세로로 찍는다.** 폰 앱 그대로. PC 크롭하면 글씨가 작아진다
- **가격 + 배지 영역만.** 상세페이지 이미지를 길게 비추지 않는다 (판매자 저작물)
- 스크롤은 한 번, 천천히. 손가락 튀는 구간은 자른다
- 개인정보 나오는 상단바(토스 로그인 상태, 잔액)는 잘라낸다
- **이 녹화가 곧 가격 근거 스크린샷이다.** 따로 안 찍어도 된다

### 편집 순서

```
단품 (items 1개)
0:00-0:03  토스 화면 녹화 (가격 + 최저가보상 배지)
0:03-0:15  Deal 그래픽 (후킹·낙차·단가·CTA)

모음 (items 3~5개)
0:00-0:03  녹화 — 제일 센 딜 하나만
0:03-0:60  Deal 그래픽 (딜 개수만큼 씬이 자동으로 늘어난다)
```

컷 넣지 말고 붙인다. 전환 0.2초.

**모음편도 녹화는 3초 하나뿐이다.** 딜마다 녹화하면 편당 시간이 5배가 되고
그러면 매일 못 낸다. 한 건이 진짜면 나머지도 진짜라고 읽힌다.

## 나레이션 — 무료 TTS

| 도구 | 무료 | 비고 |
|---|---|---|
| **클로바더빙** | 월 무료 분량 있음 | 한국어 자연스러움 1순위. 상업적 이용 조건 확인할 것 |
| 타입캐스트 | 무료 체험 제한적 | 감정 표현 좋음. 무료로 매일 돌리긴 빠듯 |
| ElevenLabs | 월 무료 크레딧 | 한국어 억양이 아직 약함 |

**클로바더빙으로 시작.** 무료 분량이 막히면 타입캐스트 유료로 넘어간다.
편당 15초면 월 90편 = 22분이라 무료로 버틸 만하다.

⚠️ **무료 플랜의 상업적 이용 가능 여부는 가입 시 약관에서 직접 확인한다.**
제휴 영상은 상업적 이용이다.

### 목소리 고르는 기준

- **30대 여성, 차분한 톤.** 소모품 구매층과 맞고 신뢰가 붙는다
- 텐션 높은 목소리 금지 — 홈쇼핑처럼 들리면 광고로 읽힌다
- **한 번 정하면 안 바꾼다**

### 넣는 순서

1. `narration` 배열을 그대로 붙여넣는다 (숫자는 이미 한글)
2. 속도 1.0~1.1. 그 이상은 싸구려로 들린다
3. 문장 사이 0.3초
4. mp3 받아서 영상에 얹는다
5. **BGM은 넣지 말거나 아주 작게.** 목소리를 덮으면 정보가 안 들린다

말해도 되는/안 되는 문장은 [plan.md](plan.md) 참고.

# 채널 운영 매뉴얼

영상은 코드가 만든다. 이 문서는 **사람이 하는 부분**만 다룬다.

---

## 컨셉

> **생활 소모품 가격만 매일 본다.
> 최저가보상 붙은 것만 올린다.
> 평소보다 얼마나 떨어졌는지 숫자로만 말한다.**

지루해 보이지만 이게 오래 간다. 자극적인 채널은 한 번 틀리면 끝난다.

### "최저가"를 어떻게 쓸 것인가

토스가 상품에 붙이는 배지는 **"최저가보상"**이지 "최저가"가 아니다. 둘은 다른 말이다.

| | 뜻 | 주체 | 안전한가 |
|---|---|---|---|
| **최저가보상** | 더 싼 데를 찾으면 차액을 보상하겠다 | 토스 | ✅ 인용이라 안전 |
| **최저가** | 여기가 제일 싸다 | 나 | ⚠️ 더 싼 데가 나오면 거짓이 됨 |

"최저가"는 표시광고법상 절대적 표현이라 **객관적 근거를 갖고 있어야** 한다.
전 쇼핑몰을 비교한 게 아니면 근거가 없다. 댓글에 더 싼 링크 하나 올라오면 그날로 끝이다.

**그래서 이렇게 쓴다.**

- ⭕ 채널 컨셉: **"최저가보상 붙은 것만 올립니다"** — 근거가 토스에 있다
- ⭕ 화면·자막: `최저가보상` 배지를 **판매 페이지에 있는 그대로** 표시 (코드가 이미 이렇게 한다)
- ⭕ 후킹: `71% 떨어졌다`, `1롤당 575원` — 원가 대비 사실이라 반박 불가
- ❌ `여기가 최저가` / `제일 쌉니다` 라고 **내가 단언하는 것**

강도는 똑같은데 리스크만 빠진다. 그리고 상품 고르는 기준도 명확해진다 —
**배지 없으면 안 올린다.**

### 왜 소모품인가

- 설명이 필요 없다 → 실사용 영상 없이 성립하는 유일한 카테고리
- 단가 비교가 그 자체로 콘텐츠 → `1롤당 575원`
- 반복 구매 → 같은 사람이 또 온다

상품 고르는 기준 하나: **`1개당 얼마`로 환산되는가.** 안 되면 이 포맷이 안 먹힌다.

## 채널 세팅

### 이름 후보

- `오늘 싸진 것만`
- `생필품 가격표`
- `자취방 장바구니`

### 소개글

```
생활 소모품 가격만 매일 봅니다.
최저가보상 붙은 것 중에 확 떨어진 것만 올려요.
가격은 영상에 적힌 시각 기준입니다.

※ 파트너스 활동의 일환으로 수수료를 제공받습니다.
```

---

## 고정 댓글 (운영의 핵심)

```
🔗 모나리자 스마트 다용도 키친타올 250매 12롤
6,900원 (1롤당 575원) · 무료배송
https://toss.im/...

7/26 오후 8시 확인 가격입니다.
품절되거나 가격 오르면 댓글로 알려주세요, 바로 수정할게요.

※ 이 게시물은 토스쇼핑 쉐어링크 활동의 일환으로,
   이에 따른 일정액의 수수료를 제공받습니다.
```

**"틀리면 알려달라"를 먼저 쓰는 게 중요하다.** 특가는 어차피 만료된다.
미리 말해두면 가격이 바뀌었을 때 거짓말쟁이가 아니라 성실한 사람이 된다.

### 만료 처리

가격이 끝나면 고정 댓글을 이렇게 바꾼다.

```
[종료] 이 가격은 끝났습니다. 지금은 23,900원이에요.
다시 떨어지면 알려드릴게요.
```

**이걸 하는 채널이 거의 없다.** 이것만 해도 신뢰가 확 다르고,
"다시 떨어지면 알려준다"는 구독 이유가 된다.

## 업로드 규칙

| | |
|---|---|
| 빈도 | 하루 1~3개 |
| 시간 | 저녁 6~9시, 매일 같은 시간 |
| 링크 | **고정 댓글에만.** 설명란에도 대가성 표기 |
| 만료 | 다음날 고정 댓글 `[종료]`로 수정 |
| 제목 | 후킹 문구 그대로 (`키친타올 1롤에 575원`) |

### 절대 하면 안 되는 것

- **카톡·단톡·오픈채팅·DM으로 링크 뿌리기** — 파트너스 약관 위반.
  적발되면 미지급 수익까지 몰수된다. 오픈채팅 핫딜방으로 벌었다는 후기는 많은데
  계정 날아간 후기는 안 올라올 뿐이다.
- **자기 구매, 지인 클릭 품앗이** — 100% 걸린다.
- **대가성 표기 누락** — 공정위 추천·보증 심사지침 위반이자 활동 정지 사유.

## 상품 고르는 순서

1. 토스쇼핑에서 생활 소모품 카테고리를 본다
2. **`최저가보상` 배지가 있는 것만** 남긴다
3. 그중 **할인율 50% 이상**이고 **단가 환산이 되는 것**을 고른다
4. 스크린샷을 찍는다 (가격이 바뀌어도 근거가 남는다)
5. `content/상품이름.json`을 채운다 → `npm run batch`

`id`는 같은 상품이면 **항상 같은 값**을 쓴다. 그래야 가격 이력이 쌓이고,
3건 넘으면 `역대 최저가` 배지가 자동으로 붙는다.

### 같은 상품을 다시 다뤄라

매번 새 상품만 찾으면 이력이 안 쌓이고, 그러면 남들과 똑같아진다.
**한 상품을 한 달에 두세 번** 다루면 3개월 뒤엔 그 상품 가격은 당신이 제일 잘 알게 된다.
그게 이 채널의 유일한 차별점이다.

## 나레이션

`narration` 배열에 적고 TTS는 직접 입힌다.

- **숫자는 한글로.** `23,900원` → `이만 삼천구백원` (엔진마다 다르게 읽는다)
- **1초에 5~6음절.** 15초면 전체 75~90음절이 한계
- **화면에 있는 말을 반복하지 않는다.** 화면은 숫자, 목소리는 맥락
- **소리 끄고 보는 사람이 절반.** 화면만으로도 성립해야 한다

## 냉정한 부분

이 판엔 이미 경쟁자가 있다. 핫딜 유튜브 채널, 텔레그램 핫딜방, 뽐뿌.
**특가 정보 자체는 흔하다.**

차별점은 하나뿐이다. **가격 이력.**
"지금 싸요"는 다 하지만 "3개월 중 제일 낮아요"는 기록한 사람만 할 수 있다.

그래서 상품을 반복해서 다루는 게 전략의 전부다.

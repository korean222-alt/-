# 실행 계획 — 정기 편성으로 전환

낱개 특가를 흩뿌리는 대신 **매일 같은 시간에 나오는 편성**으로 바꾼다.
왜 바꾸는지는 아래 관찰에서 나왔다.

---

## 무엇을 보고 이렇게 정했나

먼저 뛴 채널을 하나 봤다. 얼굴 없이 화면 녹화 + 큰 자막 + 나레이션으로
`매일 아침 8시 토스 초핫딜 이벤트 여러개 모음(한정수량 초핫딜이라 조기 품절됩니다!)`를
1분 40초짜리로 올린다. 제휴 수수료 문구를 본문 첫 줄에 그대로 달아뒀다.

댓글이 이렇게 붙어 있었다.

> `8시 핫딜 진짜좋네요 감사합니다!!!`
> `구독했어요 계속 올려주세요`
> `레알최고의채널`
> `너무 유용해서 사람들이 다 알았으면 좋겠는 마음이랑 나 혼자만 알고싶은 마음이 충돌한다`

여기서 읽어낸 것 셋.

| 관찰 | 해석 | 이 저장소가 할 일 |
|---|---|---|
| 고마움의 대상이 상품이 아니라 **8시** | 팔리는 건 상품이 아니라 **편성**이다. 정해진 시간에 대신 찾아준다는 약속에 구독이 붙는다 | 업로드 시간을 고정하고 채널 이름·소개에 시간을 박는다 |
| 수수료 표기를 대놓고 했는데 반응이 좋다 | **표기는 신뢰를 깎지 않는다.** 숨기는 게 더 비싸다 | `Disclosure` 유지, 고정 댓글에도 그대로 |
| 딜 1건이 아니라 **모음**, 그리고 1분 40초 | 하나 품절돼도 영상이 안 죽는다 | `Deal`의 `items`를 3~5개로 채운다. 포맷은 안 늘린다 |

**그리고 저 채널은 이미 선점했다.** 똑같이 하면 2등이고 2등은 이 판에서 돈이 안 된다.
이길 수 있는 자리는 하나뿐이다 — **가격 이력**. 8시에 딜을 모아주는 사람은 여럿이지만,
"이 가격은 제가 기록한 3개월 중 제일 낮습니다"를 말할 수 있는 사람은 기록한 사람뿐이다.

---

## 포맷은 `Deal` 하나. 상품 개수로만 조절한다

모음용 포맷을 따로 만들지 않는다. `Deal`이 이미 `items` 배열을 받아
개수만큼 씬을 만들고 길이를 자동으로 맞춘다 (`dealDuration`).
**포맷을 늘리는 게 아니라 JSON에 상품을 더 넣으면 된다.**

| items | 길이 | 쓰는 자리 |
|---|---|---|
| 1개 | ~15초 | 상시 특가. 반복 구매 소모품, 수명 몇 주, 롱테일 클릭 |
| 3~5개 | 40~60초 | 오늘의 딜 모음. 매일 같은 시간, 구독·재방문 |

두 갈래를 다 돌리는 이유는 **수명이 다르기 때문**이다.
한정수량 특가는 몇 시간이면 끝나는데 쇼츠 노출은 며칠에 걸쳐 붙는다.
3일 뒤에 들어온 사람이 품절 링크를 누르면 그 사람은 다시 안 온다.
모음은 하나 품절돼도 나머지가 살아 있고, 단품은 오래 사는 상품에만 쓴다.

정기 편성만 하면 채널이 오늘만 살고, 상시 특가만 하면 구독할 이유가 없다.
**같은 포맷, 다른 편성.**

---

## 나레이션 — 사람 목소리로 갈 때 지킬 선

목소리를 입히는 건 맞다. 다만 **신뢰를 만드는 건 톤이 아니라 반복되는 정확성**이다.
목소리가 아무리 자연스러워도 가격 한 번 틀리면 끝이고, 매일 맞으면 기계 목소리여도 구독한다.

그리고 목소리가 자연스러울수록 **거짓 주장이 더 잘 먹히기 때문에 더 위험하다.**
그래서 문장 단위로 선을 정해둔다.

### 말해도 되는 것

| 문장 | 왜 안전한가 | 조건 |
|---|---|---|
| `오늘 아침 8시 기준 6,900원입니다` | 확인한 사실 + 시점 명시 | 스크린샷을 남겼을 것 |
| `정가 23,900원에서 71% 내려왔습니다` | 판매 페이지에 적힌 값 | 페이지에 원가 표기가 있을 것 |
| `제가 기록한 3개월 중 제일 낮습니다` | 이력이 근거 | **기록 3건 이상** |
| `한정수량이라 아침에 품절됩니다` | 페이지 문구 인용 | 페이지에 그렇게 적혀 있을 것 |
| `최저가보상 붙은 것만 올립니다` | 근거가 토스에 있다 | 배지 있는 상품만 |
| `제가 매일 아침 확인합니다` | 실제로 하는 일 | **실제로 매일 할 것** |

마지막 줄이 이 채널이 목소리로 팔 수 있는 최대치다. 그리고 그걸로 충분하다.

### 하면 안 되는 것

| 문장 | 왜 |
|---|---|
| `원래 이 가격 거의 안 나와요` — 이력 없이 | 근거가 없으면 지어낸 말이다. **기록 3건을 채우고 나서 하면 그때부터 이 채널에서 제일 센 문장이 된다** |
| `오늘만 이 가격` — 페이지에 마감 표기가 없는데 | 없는 마감은 거짓 유인. 표시광고법 문제 |
| `제가 써봤는데 좋아요` | 실사용 거짓 주장. 공정위 추천·보증 심사지침 위반. **목소리를 입혀도 이 선은 안 넘는다** |
| `여기가 최저가예요` | 절대적 표현이라 객관적 근거가 필요하다. 전 쇼핑몰을 비교한 게 아니면 없다 |
| `품절임박` — 페이지에 없는데 | 지어낸 긴급성. 링크 누르면 바로 들통난다 |

### 목소리 운영 규칙

- **한 목소리를 정하면 안 바꾼다.** 목소리가 이 채널의 얼굴이다. 매번 바뀌면 다른 채널로 읽힌다
- **인사로 시작하지 않는다.** `안녕하세요 여러분` 하는 순간 3초가 날아간다. 첫 문장은 숫자부터
- 1초에 5~6음절. 60초 모음이면 300~360음절이 한계
- 숫자는 한글로 적는다 (`23,900원` → `이만 삼천구백원`)
- 화면에 있는 말을 반복하지 않는다. **화면은 숫자, 목소리는 맥락**
- 소리 끄고 보는 사람이 절반이다. 자막 없이 목소리만으로 성립하는 정보는 두지 않는다

## 2주 일정

가격 이력이 3건 쌓이기 전에는 제일 센 문장을 못 쓴다. 그래서 1주차의 진짜 목적은
조회수가 아니라 **기록을 시작하는 것**이다.

| | 할 것 | 끝났는지 보는 기준 |
|---|---|---|
| **1주 1~2일** | 고정 상품 5개 선정 (최저가보상 배지 + 단가 환산 되는 것). `id` 확정하고 매일 가격 기록 시작 | `price-history.jsonl`에 5개 id가 매일 들어오는가 |
| **1주 3~4일** | `Deal` JSON에 딜 3~5개 넣어 모음편 뽑기. 코드 수정 없이 `items`만 늘린다 | 40~60초 mp4가 나오는가 |
| **1주 5~7일** | 나레이션 목소리 하나 골라 고정. `Deal` 3편에 입혀 업로드. 업로드 시간 고정 | 영상 1편이 **10분 안에** 나오는가 |
| **2주 1~7일** | 매일 `DailyDeals` 1편 + `Deal` 2편. 고정 댓글 만료 처리 매일 수행 | 조회수 1,000 넘는 영상이 **하나라도** 있는가 |
| **2주 끝** | 기록 3건 넘은 상품에 `역대 최저` 문장 처음 사용 | 그 영상의 클릭률이 나머지보다 높은가 |

3~4주차와 손절 기준은 [decisions.md](decisions.md)의 표를 그대로 따른다.
**4주 뒤 조회수 1,000 넘는 영상이 0개면 접는다.**

## 매일 하는 일 (10분 루틴)

1. 토스쇼핑 소모품 카테고리에서 `최저가보상` 배지 + 할인율 50% 이상 골라낸다
2. **스크린샷을 찍는다.** 가격이 바뀌어도 근거가 남는다
3. `content/*.json` 채운다 — `id`는 같은 상품이면 항상 같은 값
4. `npm run batch` → 렌더하면서 가격이 자동 기록된다
5. **mp4로 최종 확인한다.** `npm run studio`는 기본값 누출 방어가 안 걸린다
6. 나레이션 입히고 업로드, 고정 댓글에 링크 + 수수료 문구
7. **어제 영상 고정 댓글을 `[종료]`로 바꾼다** ← 이걸 하는 채널이 거의 없다. 여기서 신뢰가 갈린다

7번을 빼먹으면 나머지 6개가 무의미해진다. 만료된 링크를 방치하는 게
이 판에서 신뢰를 잃는 제일 흔한 방법이다.

## 이 계획이 틀렸다면

가장 먼저 깨질 가정은 **"정기 편성이면 구독이 붙는다"** 이다.
저 채널의 댓글은 이미 구독자가 쌓인 뒤의 반응이라, 0에서 시작하는 쪽에서도
같은 게 작동할지는 확인된 게 아니다.

2주차 끝에 구독 전환이 안 보이면 편성을 접고 상시 특가(`Deal`) 롱테일만 남긴다.
그쪽은 구독 없이 알고리즘 노출만으로도 돌아간다.

# 졸졸 동물 기차 — Claude Code 단계별 프롬프트

## 사용하는 방법

1. 컴퓨터에 게임용 폴더를 하나 만들고(예: `animal-train`), 함께 받은 **CLAUDE.md** 파일을 그 폴더에 넣으세요. Claude Code가 이 파일을 자동으로 읽고 게임 규칙을 기억합니다.
2. Roblox Studio에서 **Baseplate** 템플릿으로 새 게임을 만들고 한 번 저장(게시)하세요.
3. Studio에서 **Assistant → Manage MCP Servers → Enable Studio as MCP server**를 켜고, 안내에 나오는 Claude Code 연결 방법을 따라 하세요.
4. Claude Code를 그 폴더에서 열고, 아래 프롬프트를 **0단계부터 순서대로 하나씩** 붙여 넣으세요.
5. 각 단계가 끝나면 **직접 Studio에서 플레이 버튼을 눌러 확인**한 뒤 다음 단계로 넘어가세요. 이상하면 다음 단계로 가지 말고 "○○가 안 돼. 고쳐줘"라고 말하면 됩니다.
6. 단계가 잘 끝날 때마다 Studio에서 **저장(Ctrl+S)** 하세요.

> 💡 한 단계가 끝나면 Claude Code에서 `/clear`로 대화를 비우고 다음 단계를 시작하면 더 정확하게 작업합니다. 규칙은 CLAUDE.md에 있어서 사라지지 않아요.

---

## 0단계 — 연결 확인

```
Roblox Studio MCP로 지금 열려 있는 Studio에 연결됐는지 확인해줘.
확인이 되면 Workspace, ServerScriptService, ReplicatedStorage 안에 무엇이 있는지 목록으로 보여줘.
아직 아무것도 만들지 마.
```

**확인할 것:** Studio 안의 폴더 목록이 제대로 나오면 성공입니다.

---

## 1단계 — 기본 폴더 구조와 설정값

```
CLAUDE.md의 기술 규칙에 맞춰 게임의 기본 뼈대만 만들어줘.

1. ReplicatedStorage 안에 Shared 폴더와 Remotes 폴더를 만들어.
2. Shared 안에 Config 모듈을 만들고 아래 값을 넣어줘.
   - 기차 최대 길이: 10마리
   - 동물 1마리 배달 시 별: 1개
   - 동물이 플레이어를 따라올 때 앞 동물과의 간격: 4 스터드
   - 두 번째 섬 해금 비용: 별 15개
3. ServerScriptService 안에 Services 폴더를 만들어.
4. 스크립트는 아직 비워 둬도 돼. 구조만 만들고 결과를 트리 모양으로 보여줘.
```

## 2단계 — 첫 번째 섬(초원 섬) 만들기

```
첫 번째 섬인 "초원 섬"을 파트로 만들어줘. 무료 모델은 쓰지 마.

- 기존 Baseplate는 지우고, 지름 약 200 스터드의 둥글고 평평한 초록 섬을 만들어. 섬 주변은 물처럼 보이는 파란 바닥.
- 섬 한쪽에 SpawnLocation을 놓아.
- 스폰 위치에서 정면으로 약 40 스터드 떨어진 곳에 "농장"을 만들어: 나무 울타리로 둘러싼 네모난 구역, 입구 하나, 입구 바닥에는 밝게 빛나는 노란 발판(이름: DeliveryZone).
- 섬 곳곳에 나무, 꽃, 바위를 파트로 간단히 배치해서 밝고 귀여운 분위기를 만들어.
- 섬 가장자리에서 떨어져도 다시 돌아올 수 있게, 물에 빠지면 스폰으로 돌아가게 해줘.
- 전체적으로 파스텔 색감, SmoothPlastic 재질을 써.

플레이 모드로 스폰 위치에서 농장이 바로 보이는지 확인해줘.
```

**확인할 것:** 스폰하자마자 농장이 눈에 보이는지, 물에 빠지면 돌아오는지.

---

## 3단계 — 병아리 만들기와 돌아다니기

```
파트를 조합해서 귀여운 병아리 모델을 만들어줘 (노란 몸통, 작은 주황 부리, 검은 눈 두 개).
이 모델을 ServerStorage/AnimalModels/Chick 에 저장해.

그다음 AnimalService 스크립트를 만들어서:
- 초원 섬에 병아리 8마리를 흩어서 스폰해. 그중 1마리는 반드시 스폰 위치 정면 약 12 스터드 앞에 둬 (접속하자마자 보이도록).
- 주인이 없는 병아리는 2~4초마다 근처로 폴짝 뛰듯이 조금씩 움직여 (섬 밖으로는 나가지 않게).
- 병아리 위에 작은 반짝임 파티클을 넣어서 멀리서도 눈에 띄게 해.
- 병아리 수가 8마리보다 적어지면 5초 뒤 새 병아리를 스폰해.

아직 따라오기 기능은 만들지 마. 플레이 모드로 병아리가 움직이는지 확인해줘.
```

## 4단계 — 닿으면 따라오기 (핵심 기능)

```
게임의 핵심 기능인 "동물 기차"를 만들어줘.

- 플레이어가 주인 없는 병아리에 닿으면, 그 병아리의 주인이 그 플레이어가 돼. 이 판단은 서버에서 해.
- 주인이 생긴 병아리는 플레이어 뒤에 한 줄로 따라와. 첫 번째 병아리는 플레이어를, 두 번째는 첫 번째 병아리를 따라가는 방식 (Config의 간격 사용).
- 따라올 때 너무 딱딱하게 붙지 말고, 부드럽게 살짝 늦게 따라오게 해줘. 점프할 때도 자연스럽게.
- 병아리가 기차에 붙는 순간 "삐약" 소리(로블록스 기본 제공 사운드 중 적당한 것)와 작은 하트 파티클이 나오게 해.
- 기차가 Config의 최대 길이에 도달하면 더 이상 붙지 않아.
- 플레이어가 나가면 그 플레이어의 병아리는 주인 없는 상태로 돌아가 다시 돌아다녀.
- 성능을 위해 따라오기 움직임은 매 프레임 물리를 과하게 쓰지 않는 방식으로 만들어줘.

플레이 모드에서 병아리 3마리를 모아서 뛰어다녀 보고, 줄이 끊기거나 벽에 끼는 문제가 없는지 확인해줘.
```

**확인할 것:** 스폰 후 10초 안에 첫 병아리를 모을 수 있는지 직접 시간을 재 보세요. 이게 이 게임의 가장 중요한 순간입니다.

## 5단계 — 농장에 배달하고 별 받기

```
FarmService를 만들어서 배달 기능을 만들어줘.

- 플레이어가 기차를 달고 농장 입구의 DeliveryZone 발판을 밟으면, 기차의 동물들이 한 마리씩 농장 안으로 폴짝 들어가.
- 한 마리 들어갈 때마다 별 1개(Config 값)를 줘. 판단은 서버에서.
- 별은 leaderstats에 "⭐" 이름으로 표시해.
- 농장 안에 들어간 동물은 농장 안에서 계속 돌아다녀서, 내가 몇 마리 데려왔는지 눈으로 보이게 해 (농장 안 최대 30마리까지만 보이게 하고 그 이상은 숫자로만 계산).
- 배달할 때 반짝이는 별이 플레이어 머리 위로 튀어 오르는 효과와 기분 좋은 효과음을 넣어줘.
- 같은 동물로 별을 두 번 받는 일이 절대 없게 막아줘.

플레이 모드로 병아리 3마리를 배달해서 별이 정확히 3개 오르는지 확인해줘.
```

## 6단계 — 글 없이 알아보는 화면(UI)

```
아이들이 글을 안 읽어도 알 수 있는 화면을 만들어줘. StarterGui에 만들고, 휴대폰에서도 크게 보이게 해.

1. 화면 왼쪽 위: 큰 별 아이콘 + 별 개수 숫자. 별이 늘면 아이콘이 통통 튀는 애니메이션.
2. 화면 위 가운데: 기차 칸 표시. 병아리 얼굴 동그라미가 최대 길이만큼 놓여 있고, 모은 만큼 색이 채워져. (예: ●●●○○○○○○○)
3. 안내 화살표:
   - 기차가 비어 있으면 가장 가까운 주인 없는 동물 위에 통통 튀는 큰 화살표를 보여줘.
   - 기차에 동물이 3마리 이상이거나 가득 차면, 화살표가 농장 입구를 가리켜.
   - 화살표는 3D 공간의 BillboardGui로 만들어.
4. 기차가 가득 차면 기차 칸 표시가 반짝이고, 농장 쪽으로 빛나는 발자국 길이 잠깐 보이게 해줘.

글자는 숫자 말고는 쓰지 마. 플레이 모드와 Studio의 휴대폰 화면 미리보기로 둘 다 확인해줘.
```

## 7단계 — 두 번째 섬(펭귄 섬)과 별 문

```
두 번째 섬인 "펭귄 섬"을 만들어줘.

- 초원 섬 옆에 눈 덮인 하얀 섬을 만들고, 두 섬 사이를 나무 다리로 연결해.
- 다리 입구에 "별 문"을 만들어: 커다란 아치 모양, 가운데 큰 별 아이콘과 "15" 숫자만 표시.
- 별이 15개 이상인 플레이어가 문에 닿으면 문이 열려 (별은 차감하지 않고, 조건만 확인. 이렇게 하면 아이가 손해 보는 느낌이 없어).
- 문은 플레이어마다 따로 열려야 해 (열린 사람만 통과 가능, 판단은 서버).
- 문이 열릴 때 폭죽 파티클과 축하 효과음.
- 펭귄 섬에는 파트로 만든 아기 펭귄 동물을 스폰해 (AnimalService를 섬별로 동물 종류를 설정할 수 있게 확장). 펭귄 1마리 배달 시 별 2개.
- 펭귄 섬에도 작은 농장(DeliveryZone)을 하나 만들어.
- 섬 해금 조건과 보상은 모두 Config에서 바꿀 수 있게 해줘.

별이 15개 미만일 때 문이 안 열리는지, 15개 이상일 때 열리는지 둘 다 테스트해줘.
```

## 8단계 — 저장하기

```
DataService를 만들어서 플레이어 데이터를 저장해줘.

저장할 것: 별 개수, 열린 섬 목록, 도감(한 번이라도 데려온 동물 종류), 최고 기차 길이 기록.
저장하지 않을 것: 현재 기차에 달린 동물 (다시 접속하면 빈 기차로 시작).

- DataStoreService를 사용하고, 저장 실패 시 몇 번 재시도해.
- 플레이어가 나갈 때, 서버가 닫힐 때(BindToClose), 그리고 2분마다 자동 저장해.
- 저장 데이터에는 버전 번호를 넣어서 나중에 구조가 바뀌어도 안전하게 해줘.
- 데이터를 불러오기 전에는 별을 주거나 문을 여는 처리가 되지 않게 막아줘.
- Studio에서 테스트할 때 "Enable Studio Access to API Services"가 꺼져 있으면 무엇을 켜야 하는지 알려줘.

별을 5개 모으고 플레이를 멈췄다가 다시 시작해서 별 5개와 열린 섬이 그대로인지 확인해줘.
```

## 9단계 — 동물 도감

```
동물 도감을 만들어줘.

- 화면 오른쪽에 큰 책 모양 버튼을 만들어. 누르면 도감 창이 열려.
- 도감에는 동물 칸이 그림으로 나열돼. 데려온 적 있는 동물은 컬러로, 아직 못 데려온 동물은 검은 실루엣으로 보여.
- 새 동물을 처음 배달하면 화면 가운데에 그 동물이 크게 나타나며 "NEW!" 스티커와 효과음이 나와.
- 도감 칸 개수를 미리 보여줘서 "아직 못 찾은 동물이 있구나"를 알 수 있게 해 (예: 초원 섬 3칸, 펭귄 섬 3칸).
- 도감 칸을 채우기 위해 각 섬에 희귀 동물을 하나씩 추가해줘: 초원 섬 "무지개 토끼", 펭귄 섬 "황금 펭귄". 희귀 동물은 서버에 1마리만 가끔(약 3분마다) 나타나고, 빠르게 도망 다니며, 배달 시 별 5개.
- 도감 데이터는 8단계의 저장 기능과 연결해줘.
```

## 10단계 — NPC 여우 기차 (혼자여도 북적이게)

```
사람이 적어도 맵이 살아 있게 NPC "여우 기차"를 만들어줘.

- 파트로 만든 귀여운 여우 캐릭터가 섬을 돌아다니며 주인 없는 동물을 모아.
- 여우도 플레이어처럼 동물이 뒤에 줄지어 따라와. 최대 5마리.
- 5마리를 모으면 섬 한쪽의 "여우 굴"로 가서 동물을 내려놓고(동물은 다시 풀려나 섬에 돌아다님), 다시 모으기 시작해.
- 여우는 플레이어보다 조금 느리게 움직여서, 아이가 "여우보다 먼저 모으자"라고 느끼게 해.
- 플레이어의 기차를 절대 빼앗지 않아.
- 여우가 플레이어 근처를 지나가면 손을 흔드는 동작을 해줘.
- 초원 섬에 1마리, 펭귄 섬에 1마리. 개수는 Config에서 조절.
- 성능을 위해 여우의 경로 계산은 너무 자주 하지 않게 해줘.
```

## 11단계 — 업그레이드 상점

```
별로 살 수 있는 업그레이드를 만들어줘. 별을 "쓰는" 첫 기능이야.

- 농장 옆에 커다란 버튼 3개가 있는 업그레이드 가판대를 파트로 만들어. 버튼 위에는 그림과 가격 숫자만 표시.
  1. 신발 그림: 달리기 속도 UP (3단계)
  2. 기차 그림: 최대 기차 길이 +5 (3단계)
  3. 자석 그림: 동물에 닿는 범위가 넓어짐 (2단계)
- 가격은 단계마다 올라가고 모두 Config에서 조절.
- 버튼을 밟으면 구매. 별이 모자라면 버튼이 흔들리고 "뽁" 소리만 나고 아무 일도 안 일어나.
- 구매 판단은 서버에서 하고, 업그레이드 단계는 저장 데이터에 추가.
- 주의: 7단계 별 문은 "보유한 별"이 기준이었는데, 이제 별을 쓰면 문 조건이 헷갈릴 수 있어. 섬 해금 조건을 "지금까지 모은 총 별"로 바꾸고, 저장 데이터에 총 별을 따로 저장해줘.

별을 충분히 모은 상태와 부족한 상태를 모두 테스트해줘.
```

---

## 12단계 — "10초 테스트"와 다듬기

```
처음 접속한 아이 입장에서 게임 전체를 점검하고 다듬어줘.

1. 새 플레이어 데이터로 플레이 모드를 시작해서 아래 시간을 측정하고 보고해줘:
   - 접속 → 첫 동물에 닿기까지
   - 접속 → 첫 별 받기까지
   - 접속 → 첫 업그레이드 가능해질 때까지
   목표: 10초 이내 / 60초 이내 / 3분 이내. 목표를 넘으면 원인과 고칠 방법을 제안해줘.
```

## 문제가 생겼을 때 쓰는 프롬프트

**오류가 날 때**
```
플레이 모드 출력 창에 나오는 오류를 확인하고 원인을 설명한 뒤 고쳐줘. 고친 다음 다시 플레이해서 오류가 없어졌는지 확인해줘.
```

**동작이 이상할 때**
```
[어떤 상황에서] [무엇을 했더니] [어떻게 됐어]. 원래는 [어떻게 되길] 바랐어.
먼저 원인을 찾아서 설명해 주고, 고치기 전에 어떻게 고칠지 말해줘.
```

**코드가 너무 복잡해졌을 때**
```
지금까지 만든 스크립트들을 살펴보고, 기능은 그대로 두면서 중복되거나 복잡한 부분을 정리해줘. 정리한 뒤 모든 기능을 다시 테스트해줘.
```

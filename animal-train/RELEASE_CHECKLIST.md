# 13단계 — 출시 준비 체크리스트

## A. 코드 쪽 (이미 해 둔 것)

| 항목 | 상태 |
| --- | --- |
| 별·배달·해금·구매를 서버에서만 결정 | ✅ 클라이언트는 화면 표시와 음악 설정만 보냅니다 |
| 클라이언트가 보내는 값 검증 | ✅ `SetPref` 는 `music`(true/false)만 받습니다 |
| 같은 동물로 두 번 별 받기 방지 | ✅ 기차에서 꺼낸 즉시 `consumed` 표시 |
| 데이터 불러오기 전 보상 금지 | ✅ `DataService.isLoaded` 가 아니면 배달·구매·해금 모두 막힘 |
| 저장 재시도 | ✅ 4회, 대기 시간 2배씩 늘림 |
| 서버 종료 시 저장 | ✅ `BindToClose` |
| 자동 저장 | ✅ 2분마다 + 나갈 때 |
| 저장 구조 버전 | ✅ `version = 2`, 빠진 값은 기본값으로 채움 |
| 모바일 UI | ✅ 화면 비율 기준 배치 + 최소/최대 크기 제한, 상단바·조이스틱 영역 피함 |
| 툴박스 모델 미사용 | ✅ 전부 파트 조합 (악성 스크립트 위험 없음) |
| 성능 | ✅ 동물은 Anchored + CFrame 이동(물리 없음), 돌아다니기 15Hz, 여우 경로 1.5초마다 |

## B. 직접 하실 일 (Studio / Creator Hub)

1. **Studio 에서 플레이 테스트**
   - Play(F5) 로 위 README 의 체크리스트 확인
   - Device → Phone 으로 바꿔 UI 확인
   - 출력 창(Output)에 빨간 오류가 없는지
2. **게시**: File → Publish to Roblox As… → 이름 입력
3. **API 서비스 켜기**: HOME → Game Settings → Security →
   `Enable Studio Access to API Services` 켜고 저장 (저장 기능이 여기서 켜집니다)
4. **게임 설명** 아주 짧게: 예) `동물 친구들을 모아서 농장에 데려다줘!`
5. **아이콘과 썸네일**: 게임 화면을 직접 캡처해서 만들기
   (다른 게임 캐릭터·이미지 사용 금지)
6. **성숙도(콘텐츠) 설문** 작성 — 폭력·무서운 표현 없음으로 답하면 됩니다
7. **배경 음악**(원하면): 크리에이터 스토어에서 사용 허용된 음악 ID 를
   `Shared/Config` 의 `Config.Music.AssetId` 에 넣기
8. **공개 설정**: Creator Hub → 게임 → Permissions → Public
9. **친구·가족 테스트**: 아무 설명 없이 시작하게 하고,
   멈칫하는 순간(어디로 갈지 모르는 지점)을 적어 두기 → 그 지점에 화살표나 반짝임 추가

## C. 출시 후 추가하면 좋은 것

- 세 번째 섬 (공룡 섬, 사탕 섬)
- 모자·기차 꼬리 장식 꾸미기
- 다른 플레이어와 나란히 달리면 둘 다 속도 UP
- 주간 이벤트 동물 (할로윈 호박 병아리 등)

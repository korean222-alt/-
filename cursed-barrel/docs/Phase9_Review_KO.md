# 저주받은 통 — Phase 9 통합본

2026-09-22 · 기반: 첨부 CursedBarrel_Phase8.rbxl

## 이번에 바뀐 핵심

- 넓은 항구 플랫폼 대신 **게임을 실제로 진행하는 선박형 로비**를 코드로 구성했습니다. 좌우 10개 테이블, 중앙 통로, 선체와 난간, 돛대와 돛, 대포, 화물, 선수 갑판, 선미 상점 선실, 계단으로 올라가는 후갑판과 조타륜을 배치했습니다.
- 복도 랜턴에는 기둥·가로보·체인을, 선실 랜턴에는 벽 브래킷을 붙였습니다. 공중에 떠 있던 기존 장식 생성 경로는 사용하지 않습니다.
- **사용자 이미지 원본 세 장만** 최종 ZIP에 넣었습니다. 첫 번째 정사각형은 프로필, 두 번째 가로형은 썸네일, 세 번째 SHOP 보물상자는 상점 버튼입니다. 이전에 생성했던 홍보 이미지는 포함하지 않습니다.
- 청해룡·적염룡·월백룡 테마, 칼/통/해적 용 장식, 용의 심판 탈락 연출과 쌍룡 승천 승리 연출, 의자 스킨, 회전 가능한 3D 미리보기를 추가했습니다. 용은 뿔·턱·송곳니·수염·등뼈를 조합한 절차적 모델입니다. 첨부 홍보 이미지 수준의 렌더링을 게임에서 검증했다는 뜻은 아닙니다.
- 파티 카드(넘기기/회전/봉인), 관전과 다음 판 참가, AFK 처리, 주간 퀘스트·시즌 보상, 같은 서버 파티·친구 보너스, 설정 저장을 통합했습니다.
- 프로필 세션 잠금, 저장 재시도, 모든 정상 참가자 정산, 중도 이탈 제한, 저장 성공 후 구매 승인, 영수증 중복 지급 방지를 보강했습니다. 방해 상품은 구매 즉시 대상을 공격하지 않고 저장되는 사용권으로 지급합니다.

## 반드시 알아둘 점

1. **새 선박은 Studio에서 Play를 누르면 생성됩니다.** 편집 화면에는 원래 맵이 남아 있을 수 있습니다. 실행 중 옛 로비 장식은 ServerStorage의 Phase8_LobbyBackup에 보관합니다. 입력 원본 파일도 ZIP의 base에 보존했습니다.
2. **이미지 에셋 ID 입력이 아직 필요합니다.** 로컬 JPEG를 Roblox ImageButton에 직접 넣을 수 없습니다. `assets/branding/BRANDING_SETUP.md`에 따라 세 번째 이미지를 업로드하고 `ReleaseConfig.Branding.ShopImage`에 발급된 숫자 ID를 입력하세요. ID가 0이면 SHOP 글자 버튼이 표시됩니다. 프로필과 썸네일은 Creator Dashboard에 각각 업로드하세요.
3. 실결제 상품·배지·음악의 계정별 ID는 임의 생성하지 않았습니다. 발급 및 연결 전에는 해당 외부 기능이 출시 완료 상태가 아닙니다. 원본 합성 WAV 5개와 업로드 연결 위치는 ZIP에 들어 있습니다.
4. 공개 규칙은 최소 2인입니다. 1인 개발 테스트만 하려면 `ReleaseConfig.StudioSolo = true`로 바꾸세요. Studio에서만 적용됩니다. Studio API가 꺼진 임시 프로필에서는 저장/구매 기능을 안전상 제한합니다.
5. **Roblox Studio 실행, 실제 멀티플레이·모바일 FPS, 실제 DataStore/결제는 미검증입니다.** 파일 구조 검사와 모의 검사를 실제 엔진 검증으로 대체하지 않았습니다. 공개 배포도 수행하지 않았습니다.

## 먼저 해볼 순서

1. 최종 rbxl을 **비공개 테스트 Place**에서 열고 Play. Output의 빨간 오류와 선박/테이블 10개 생성 확인.
2. Studio에서 서버+클라이언트 2개를 시작해 착석 → 선택 → 해적 잡기 → 탈락/우승 → 다음 판을 확인.
3. 선수에서 중앙 통로 → 선미 선실 → 양쪽 계단 → 조타륜까지 걸어보기. 좌석 접근, 카메라 벽 끼임, 난간 충돌 확인.
4. 상점에서 스킨 3D 미리보기, 용 스킨 장착과 위험/승리 연출 확인. 저사양/효과 줄이기 설정도 비교.
5. 이미지·음악·상품·배지 ID 연결 후 별도 테스트 계정으로 저장과 구매 재접속 검증.

로드맵 전체의 구현/보류 구분, 공개 전 체크리스트, 게임 설명 초안과 재빌드 방법은 소스 ZIP의 docs에 있습니다. 계정 설정·실기기 검증·실제 음원/이미지 승인까지 모두 끝난 공개 출시본으로 간주하지 마세요.

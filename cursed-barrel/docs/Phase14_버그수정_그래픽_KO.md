## 3D 모델 ID (칼 · 통 · 대포)

코드로 만든 모양은 한계가 있습니다. 모델(메시) ID 를 넣으면 그 모델로 바뀝니다.

1. Studio → 도구 상자 → 모델에서 검색 (예: `cutlass`, `pirate dagger`, `wooden barrel`, `ship cannon`)
2. 넣은 모델 안의 **MeshPart** 를 클릭 → 속성의 **MeshId** · **TextureID** 에서 숫자만 복사
3. 저에게 보내 주시거나 `ReleaseConfig.lua` 의 `C.Meshes` 에 직접:

```lua
C.Meshes = {
 Knife = { gold = { MeshId = 123, TextureId = 456 } },   -- 칼 스킨 id 마다
 Barrel = { oak = { MeshId = 123, TextureId = 456 } },   -- 통 스킨 id 마다
 Cannon = { MeshId = 123, TextureId = 456, Scale = Vector3.new(1, 1, 1), Offset = Vector3.new(0, 0, 0) },
}
```

크기가 안 맞으면 `Scale` 만 고치면 됩니다. 스킨 id 는 `GameConfig.lua` 의 `id = "..."` 입니다.

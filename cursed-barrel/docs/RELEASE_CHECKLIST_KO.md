# 비공개 검증과 출시 체크리스트

## 시작

- 원본을 덮어쓰지 말고 비공개 테스트 경험에서 최종 rbxl을 연다.
- Play에서 선박이 생성되는지 확인한다. 생성 전에 테이블 위치를 바꾸고 이후 게임 로직이 좌석/슬롯 좌표를 읽도록 구성했다.
- 선택적으로 `tests/StudioSmoke.server.lua`를 ServerScriptService에 복사해 자동 구조 검사를 실행한다. 공개 전에 제거한다. 이 스크립트도 이번 환경에서는 실행하지 않았다.
- 실제 저장 검증은 운영 데이터와 분리된 테스트 경험을 사용한다. 운영 저장소에 임의 테스트 잔액을 넣지 않는다.

## 이미지·사운드·유료 기능

- 사용자 프로필/썸네일/상점 JPEG는 `assets/branding/BRANDING_SETUP.md`의 순서대로 업로드.
- 음원은 `assets/audio`: lobby_harbor → ReleaseConfig.Audio.Lobby, match_tension → Match, dragon_roar → Dragon, knife_impact → Impact, victory_fanfare → Win.
- 음원 5개는 원본 합성 WAV다. Roblox 업로드·검토·권한은 소유자가 확인한다. 기존 기본 효과음 ID의 실제 사용 권한도 점검한다.
- `GameConfig`의 Developer Product IDs를 본인 경험의 상품으로 연결한다. 표시 가격과 실제 결제 창을 대조한다.
- Phase 10 상품:
  - `GameConfig.Products.Starter.productId`: 개발자 상품, 추천 49 R$, 계정당 1회
  - `GameConfig.Products.GamePasses.VIP.gamePassId`: 게임패스, 추천 199 R$
  - ID 가 0 이면 공개 서버에서 상점에 보이지 않는다. 코인 묶음과 방해 아이템도 같다.
- Phase 12 상품 (전체 표 · 만드는 법: `docs/Phase12_에셋_상품_안내_KO.md`):
  - `GameConfig.Products.GamePasses.Booster.gamePassId`: 현상금 부스터 게임패스, 추천 149 R$
  - `skin_storm_victory.productId` (GameConfig.lua 아래쪽 `table.insert` 줄): 승리 세리머니 「폭풍의 군주」, 추천 99 R$
  - `ReleaseConfig.Badges` 의 `cannon100` · `raid10` · `crew5` · `tourney34` (선택)
  - `ReleaseConfig.Audio` 의 새 칸 12개(Night · Storm · Rain · Thunder · KrakenRoar · Slam · WoodCrack · Cannon · Splash · Hit · Coins · Waves). 0 이면 Roblox 기본 소리로 대신한다.
- Phase 11 상품: `GameConfig.Products.Skins` 의 `skin_ember_stab.productId` (칼 꽂기 모션 「잿불 강타」, 추천 79 R$). 0 이면 목록에는 보이지만 누르면 "준비 중"으로 거절된다.
- VIP 로 확인할 것: 게임 코인 +20%, 전용 칼 지급, 머리 위 VIP 표시, 재접속 후 유지, 구매 직후 바로 적용(PromptGamePassPurchaseFinished).
- 스타터 팩으로 확인할 것: 코인 2,500 + 「선원의 갈고리」, 구매 후 상점에서 버튼이 사라지는지, 같은 영수증 재처리 시 중복 지급이 없는지.
- `ReleaseConfig.Badges`에 본인 경험의 배지 ID를 연결한다.
- 결제 취소/중복 영수증/서버 이동/지급 중 종료/저장 실패를 테스트한다. 데이터 저장이 불가하면 결제 승인을 유보하는지 확인한다.
- 방해 상품은 사용권 적립 후 대상을 선택해 사용한다. 게임 결과에 영향을 줄 수 있는 기존 상품이므로 공개 판매 여부와 공정성을 먼저 결정한다.

## 실제 플레이

- Phase 12 규칙 (`GameConfig.World.StudioStartPhase = "storm"`, `StudioTimeScale = 0.2` 로 빨리 확인하고 되돌린다):
  - 항해 시계: 오른쪽 위 단계 표시, 하늘 · 안개 · 비 · 번개 전환, 단계별 규칙(노을 보물 폭발 2배, 밤 +25% · 빠른 해적, 안개 번호 가림, 폭풍 현상금 2배 · 해적 +1).
  - 습격: 내려치기 경고(치켜든 다리 · 떨림) → 쾅(흔들림 · 소리 · 파편) → 물러남. 테이블 게임 중에는 흔들림이 아주 약한지. 설정의 흔들림 끄기 · 연출 줄이기.
  - 대포: 앉기 · 조준 · 발사 · 내리기(버튼 · 스페이스 · B · 멀리 걷기 · 90초), 한 대포에 한 명, 맞힌 곳과 판정 일치, 하루 코인 상한, 막기와 체력 감소, 승리 · 도망 보상.
  - 토너먼트(J): 4판 점수, 기권 절반, 나가면 끊김, 순위판(DataStore), AI 가 앉지 않는지.
  - 행운 테이블 🍀, 관전 예측(한 바퀴 뒤 닫힘 · 참가자 금지 · 적중 보상), 연습 판(AI 둘 · 안내 카드), 친구 초대 보상, 칭호 표시.
- Phase 11 규칙:
  - 해적이 나오기 전에 한 번 누르면 바로 탈락하는지, 칼을 고른 직후의 두 번째 탭은 무시되는지 확인한다. (PC 클릭 · 모바일 탭 · 게임패드)
  - 잡을 때마다 창이 짧아지고(머리글 "잡기 N회 · 다음 해적은 더 빠르다"), 6번 잡은 뒤에는 "분노한 해적"으로 탈락하는지 확인한다.
  - 가짜 손 · 덜컹거림 · 뚜껑 폭발 뒤 뚜껑이 제자리로 돌아오는지 확인한다.
  - 시작 직후 상대가 나가면 기권승 보상이 절반이고, 남은 현상금이 다음 판에 "이월"로 얹히는지 확인한다.
  - 혼자 앉아 6초 뒤 AI 선원이 앉는지, 의자 자세 · 이름표("AI ...")가 자연스러운지, 사람이 더 오면 AI 가 비켜 주는지 확인한다.
  - AI 와 한 판: AI 가 스스로 고르고 잡는지, 이기면 코인이 60% 이고 승수 · 랭킹이 오르지 않는지, 내가 탈락하면 판이 바로 끝나는지 확인한다.
  - 보물 폭발 금화 비, 금화 더미, 승자에게 금화가 날아가는 연출과 FPS 를 확인한다.
  - 칼 꽂기 모션 7종을 상점 "보기"와 실제 판에서 확인한다. (R15 · R6 · AI)
- Phase 10 규칙 (Phase 11 에서 바뀐 것 제외):
  - 잡기 도중 스페이스·게임패드 A 연타, 채팅 입력 중 잡기 창을 확인한다. 의자에서 일어나거나 잘못 판정되면 안 된다.
  - "한 번 더"를 1~3단계까지 눌러 보고, 보상과 현상금 증가, 다음 사람 차례에서 배짱 단계 초기화를 확인한다.
  - 안전한 자리 결과(2.2초) 중 차례인 사람이 나가도 다음 사람이 건너뛰어지지 않는지 확인한다. 탈락 연출 중 앞사람이 나가는 경우도 본다.
  - 시작 직후 상대가 나가면 "기권승"으로 표시되는지, 승리·연승이 없는지 확인한다.
  - 연속 출석: 날짜를 바꿔(테스트 계정) 1→2일째 보상과, 하루 건너뛸 때 1일째로 돌아가는지 확인한다.

- 2/3/4/6인, 여러 테이블 동시 진행, 20라운드 연속.
- 안전/위험/잡기 성공·실패/통 재충전/슬롯 소진/최후 2인/승리 초기화.
- 착석 중 리셋·퇴장, 잡기 중 퇴장, 카운트다운 이탈, 동시 마지막 탈락, Resetting 요청.
- H 테이블 카드 각 1회: 패스/회전/봉인, 봉인 후 패스 및 다음 선택, 오래된 라운드 요청 거절.
- 관전 중 선택 차단, 다음 판 참가 거리 제한, AFK 180초와 3회 시간 초과.
- 파티 초대 만료/수락/탈퇴/리더 퇴장, 친구 보너스, 일일·주간·시즌 중복 수령 차단.
- 스킨 구매·재장착·재접속 유지, 여섯 카테고리 3D 회전 미리보기, 용/승리/탈락 이펙트 동시 발생.

## 선박과 기기

- 크라켄(클라이언트 전용 장식):
  - 다리 10개와 머리가 보이는지, 갑판 통로·좌석·대포·계단·조타륜을 막지 않는지 확인한다.
  - 카메라가 다리 옆으로 가면 반투명해지는지, 테이블 게임 중에는 보이지 않는지 확인한다.
  - 모바일(효과 품질 낮음)과 "연출 줄이기"에서 FPS를 비교한다.

- 선수 스폰에서 내려와 모든 테이블 좌석과 선미 선실, 양쪽 계단, 후갑판 조타륜까지 이동.
- 계단 턱/선실 입구/난간·장식 끼임, 테이블 주변 카메라 충돌, 스트리밍 이동 시 빈 바닥 확인.
- PC, iPhone/iPad, Android 저사양, 게임패드에서 UI 겹침과 터치/포커스 확인.
- 1시간 실행하며 FPS·메모리·인스턴스/연결 수·Output 오류를 측정한다. 이번 버전의 실제 측정치는 없다.

## 소유자 승인과 공개

- 이름·설명·이미지, 최대 서버 인원, 리셋·채팅·음성채팅·개인 서버 설정 확정.
- 콘텐츠/연령 설문은 실제 게임 동작을 보고 소유자가 작성. 개인정보 저장 범위와 계정 정책 검토.
- 저장 범위: 게임 기록/코인/스킨·장착/퀘스트·시즌/설정/튜토리얼/구매 영수증·사용권/세션 잠금. 외부 개인정보 수집 기능은 추가하지 않았다.
- 소규모 비공개 테스트 통과 후에만 공개. Analytics 이벤트 수신과 첫 게임 완료율·라운드 시간·이탈률 확인.
- 핫픽스: 재현 → 비공개 패치 → 모의 검사/Studio 회귀 검사 → 버전 보관 → 공개. 데이터 스키마 3으로 저장한 이후 구버전으로 단순 롤백하면 데이터 손실 위험이 있으므로 호환성 검토 없이 Phase 8 서버로 되돌리지 않는다.

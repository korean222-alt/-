## 사용법 — 항해 수첩 · 방해

**🧭 항해 수첩** (왼쪽 🧭 항해 버튼)
- 관전: 다른 테이블 판 구경하기 (구경하면서 승자를 맞히면 코인)
- 의뢰: 주간 의뢰(일주일 목표)와 시즌 보상. 다 채우면 「받기」 — 받을 게 있으면 버튼에 빨간 동그라미
- 파티: 친구 초대 · 파티 만들기 (친구와 함께 하면 코인 +10%, 파티 +5%)
- 방법: 게임 방법 7줄 요약 (새로 넣음)
- 설정: 음악 · 효과음 · 화면 흔들림 · 화각 넓게 · 이펙트 품질 · 언어 · 자리 비움

**😈 방해** (왼쪽 😈 방해 버튼)
1. 테이블에 앉아 **게임 중일 때** 엽니다 (게임 밖에서는 "테이블에서 게임 중일 때 쓸 수 있어요")
2. 아이템(먹물 · 흔들리는 손 · 재촉 · 뒤섞인 번호 · 해적의 포효)을 고르고 방해할 상대를 누릅니다
3. 로벅스 결제창 → 결제가 끝나면 그 상대에게 **바로** 쓰입니다. 그 사이 판이 끝났으면 가방에 남고 다음에 쓸 수 있음
- 상대는 진짜 사람만 (AI 선원은 목록에 안 나옴). 한 번 쓰면 잠깐 쿨타임
- ⚠️ 지금은 상품 ID 가 비어 있어서 **실제 게임에서는 "준비 중"** 으로 막힙니다. Studio 에서는 무료로 시험됩니다. 팔기로 정하시면 상품 5개를 만들어 ID 를 보내 주세요 ([할 일 3장](할일_총정리_KO.md#3-로벅스-상품-만들기-creator-hub))
- 시험: Studio → 테스트 → **클라이언트 및 서버 → 플레이어 2명** 으로 시작해 같은 테이블에 앉기

## 해 주실 것

1. Studio 에서 `CursedBarrel_Phase15_Kraken.rbxl` 열기
2. **블렌더 모델 가져오기 (한 번만)**
   1. **홈 → 3D 가져오기(Import 3D)** → `assets/models/CursedBarrelModels.fbx` 선택
   2. 가져오기 창 오른쪽 **파일 지오메트리**에서 **"배율 조정 값" 을 `0.01`** 로 바꾸고, **"메시 병합" 은 끈 채로** 둡니다 (조각 21개가 따로 있어야 합니다). 나머지 설정은 그대로
      - 1 로 두면 "파일 크기"가 17702 처럼 100배로 나오고 ⚠️ 가 뜹니다 (Roblox 메시 크기 한도 초과). 0.01 로 바꾸면 ⚠️ 가 사라집니다. 게임이 크기 · 자리를 다시 맞추므로 0.01 이어도 제 크기로 보입니다
   3. **가져오기** → Workspace 에 `CursedBarrelModels` 모델이 생깁니다. 위치 · 크기는 신경 안 쓰셔도 됩니다 (게임이 자리를 맞춤)
   4. **파일 → Roblox에 게시** (가져온 메시가 올라가서 게임에서 보입니다)
   - 안 해도 게임은 돌아갑니다. 그때는 예전(파트로 만든) 통 · 대포 · 크라켄이 보입니다
   - 출력 창에 `Blender 모델 'Cannon' 없음` 같은 줄이 뜨면 가져오기가 안 된 것입니다
3. Play 로 확인 (아래 체크)

### Play 체크

- [ ] 배 난간 밖으로 뛰어내림 → 곧바로 갑판으로 돌아오고 "💦 풍덩!"
- [ ] 오른쪽 가운데에 📅 출석 · 🎡 룰렛 (룰렛에 확률표 없음)
- [ ] 상점 연 채로 출석 누르기 → 상점이 닫힘
- [ ] 상점 줄마다 스킨 3D 모습
- [ ] 퀘스트 하나 채움 → 📜 버튼 위 빨간 숫자
- [ ] 4인 테이블(AI 포함)에서: 위 가운데 "라운드 1/3", 한 명 떨어지면 "2 라운드!", 마지막 둘은 "결승"
- [ ] 판 도중 코인은 안 늘고 👑 현상금이 커짐 → 이기면 "승리!" + 현상금 전부, 지면 "패배"
- [ ] 게임 중 드래그 · A/D 로 시점이 좌우로 돔
- [ ] `GameConfig.World.StudioStartPhase = "night"` 로 Play → 들어오자마자 등불이 켜져 있음 (확인 뒤 `nil`)
- [ ] 블렌더 모델을 가져왔다면: 뒤쪽 조타 갑판 · 오른쪽 갑판 가장자리에 누운 크라켄 다리, 새 통 · 대포 모양

# 전체 로드맵 대조

기준: 첨부된 Phase 3 이후 전체 개발 로드맵과 Phase 6–8 설명. 사용자 최신 요청에 따라 선술집 환경은 선박형 로비로 변경했습니다.

## 기본 운영 값

- 시즌: 2026-09-01 00:00 UTC부터 2027-01-01 00:00 UTC 미만. `ReleaseConfig.Season`에서 수정.
- 친구 보너스 10%, 같은 파티 보너스 5%. 각각 조건 충족 시 적용; 밸런스 수치는 최종 확정 전 테스트.
- 효과 동시 버스트 상한 3, 관찰 거리 110스터드, 용 세그먼트 고품질 22 / 낮음 10.
- 위험 슬롯의 실제 위치는 서버 메모리에만 유지. 카드 요청에는 라운드/턴 식별자 필요.
- 미지정 외부 에셋/상품/배지 ID는 0. 실제 ID나 소유권을 추정해 넣지 않음.

전체 로드맵을 ‘출시 완료’로 체크하지 않았습니다. 엔진·기기 검증과 소유자 계정에서 해야 하는 설정, 위 표의 미구현 범위가 남아 있습니다.

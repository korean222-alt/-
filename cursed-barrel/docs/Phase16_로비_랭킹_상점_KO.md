### 돈 그림은 두 가지로 보입니다

- **지금 바로**: 같은 모양을 파트로 만든 작은 3D 모형이 보입니다. 아무것도 안 하셔도 됩니다.
- **더 예쁘게 (선택)**: `assets/ui/money/*.png` (검은 외곽선 만화풍, 투명 배경) 9장을 올려서 ID 를 `ReleaseConfig.lua` → `C.Images.Money` 에 넣으면 그 그림으로 바뀝니다.
  - `cash` · `cash2` · `cash3` · `coins` · `chest` · `vault` · `gift` · `crown` · `potion`
  - 올리는 법: Studio → 보기 → 에셋 관리자 → 가져오기 → 올라간 그림 오른쪽 클릭 → Copy Asset ID

### 개발자 코드 `gnsdl23091`

- **개발자 계정에서만** 됩니다. 다른 사람이 코드를 알아내도 "없는 코드예요" 가 뜹니다.
  - 개발자 = Studio 에서 Play · 게임을 만든 계정 (그룹 게임이면 그룹 주인 · 순위 254 이상)
  - 친구에게도 시험을 맡기려면 `CodeService.lua` 의 `DeveloperUserIds` 에 그 사람 UserId 숫자를 넣으세요.
  - 이렇게 막은 이유: 코드는 GitHub 에도 올라가 있어서, 누구나 쓸 수 있으면 999,999 코인이 퍼져 게임 경제가 망가집니다.
- 이 코드를 쓴 계정은 **랭킹에 올라가지 않습니다** (999,999 코인이 부자 순위 1등을 차지하지 않게).
- 코드 목록은 서버에만 있습니다: `ServerScriptService/CursedBarrel/Services/CodeService.lua`
  - 누구나 한 번 쓰는 출시 기념 코드 `cursedbarrel` (1,500 코인)도 하나 넣어 두었습니다. 바꾸거나 지워도 됩니다.
  - 새 코드: `이름 = { coins = 2000 }`. 기간을 두려면 `expires = 끝나는 시각(os.time 숫자)`.

### 좋아요 보상에 대해

- Roblox 는 **좋아요를 눌렀는지 게임에 알려 주지 않습니다.** 그래서 "눌렀어요!" 를 누르면 믿고 줍니다 (다른 게임들도 같은 방식).
- 그룹이 있으면 `ReleaseConfig.lua` → `C.GroupId` 에 그룹 숫자를 넣으세요. 그러면 **그룹 가입은 실제로 확인**하고, 안 했으면 가입 창을 띄웁니다 (사진의 "그룹 가입 + 게임 좋아요"처럼).
- 좋아요를 보상 조건으로 거는 것에 대한 Roblox 안내가 바뀔 때가 있으니, 공개 전에 한 번 확인해 주세요.

| 오른쪽 버튼 줄 | 출석 · 룰렛 · 코드 3개가 들어가게 늘렸습니다. 점프 버튼(오른쪽 아래)과 겹치지 않는 높이입니다 |
| 창 크기 | 위쪽 Roblox 메뉴 줄을 뺀 실제 화면에 맞춥니다. 상점은 휴대폰에서 너무 작아지지 않게 0.72배까지만 줄이고, 대신 창 높이를 화면에 맞춰 낮춥니다 (카드는 스크롤) |

| 그림 · 룰렛 | 창이 닫혀 있으면 도는 그림 · 전구 반짝임을 멈춥니다. 룰렛은 판 대신 카메라를 돌려 파트를 움직이지 않습니다 |
| 원래 잘 되어 있던 것 | 휴대폰은 자동으로 효과 "낮음" (크라켄 마디 수 · 움직임 횟수 줄임) · 스트리밍 켜짐 · 칼 고르기 버튼 46px · 칼 고르는 창은 점프 버튼 위로 띄움 · 손가락으로 끌어 시점 돌리기 · 대포 터치 조작 |

## 해 주실 것

1. Studio 에서 `CursedBarrel_Phase16_Lobby.rbxl` 열기
2. (Phase 15 에서 안 하셨으면) 블렌더 모델 가져오기: 홈 → 3D 가져오기 → `assets/models/CursedBarrelModels.fbx` → "단일 메시로 가져오기" 끄기 → 가져오기
3. (선택) 돈 그림 9장 올리고 ID 를 `C.Images.Money` 에 · 그룹 ID 를 `C.GroupId` 에
4. Play 로 확인 (아래) → 게시

### Play 체크

- [ ] 스폰에서 앞을 보면 나무판자 랭킹판 셋 (연승 · 부자 · 승리), 가운데 판 아래로 계단을 내려갈 수 있다
- [ ] 스폰 오른쪽 파란 드럼 받침대 → 받기 → 창 → 「👍 눌렀어요! 받기」 → 통이 파란 드럼으로 바뀜 · 다시 누르면 "받았어요 ✔"
- [ ] 오른쪽 🎟 코드 → `gnsdl23091` → 🪙 999,999 (Studio 에서는 개발자로 인정됩니다)
- [ ] 상점: 왼쪽 분류 버튼 · 카드마다 그림 · 값 버튼 · 그림 누르면 3D 로 크게
- [ ] 출석판 칸마다 돈 그림, 7일째 보물 상자
- [ ] 룰렛: 색 칸 · 금테 · 전구 · 바늘. 돌리면 칸 글자가 판과 같이 돈다
- [ ] Studio 기기 보기(휴대폰 가로)에서 버튼 크기 · 상점 글씨가 읽히는지

## 못 한 것 · 알아 두실 것

- Studio 에서 실제 화면은 못 봤습니다. 돈 그림과 룰렛은 Blender 로 같은 모양을 그려 확인했고, 규칙은 자동 검사(동작 110개 · 크라켄 겹침 269만 번 · Place 구조)로 확인했습니다. 어색한 곳은 캡처를 보내 주세요.
- 전 서버 랭킹은 저장소(DataStore)를 씁니다. Studio 에서 "API 서비스 사용"이 꺼져 있으면 이 서버 순위만 보입니다.
- 코인 · 연승 순위는 2분마다 올라갑니다 (저장소 쓰기 한도를 아끼려고). 승리는 이기는 즉시.
- 돈 그림 · 룰렛 미리보기 다시 만들기: `python3 tools/blender/money_icons.py --parts` · `python3 tools/blender/roulette_preview.py`
